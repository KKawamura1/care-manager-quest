# Care Manager Quest 2021（第24回）追加データ

- `data/care_manager_2021_all60.json`: 2021年全60問の問題テキスト、5選択肢、正答、必要選択数、分野・知識分類
- `data/care_manager_2021_index.csv`: 分類・正答の一覧
- `assets/questions/2021/q01.png` ... `q60.png`: ユーザー提供の公式PDFから切り出した確認用の原本画像
- `verification_report.txt`: 検証状況と残課題
- `WORK_IMPORT_PROMPT.md`: アプリ取り込み指示

原文テキストはOCR補助で作成。専門用語・数字を優先して一部修正しましたが、独立した二重校正は未実施です。**画像を正本**とし、データの誤字・脱字等を修正する際には原本に忠実に修正してください。法改正に合わせて問題文自体を書き換えないでください。

IDは `2021-01` 〜 `2021-60` です。過去年次との衝突を避けるため、このIDを維持してください。 `primary_group`・`primary_concept_id`・`related_groups` は分類変更を想定した暫定値です。解答は `correct_choices` の完全一致で採点します。

初期出題対象は介護支援分野（問1〜25）とし、設定で他の35問も選べるようにしてください。

出典: 東京都福祉局公開 第24回介護支援専門員実務研修受講試験。試験センターの過去問題利用条件を遵守してください。
