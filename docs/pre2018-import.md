# 2005〜2017年度の民間掲載過去問

13年度×60問＝780問を保存し、採点対象外の2005年問28を除く779問を通常出題する。2018〜2025年度480問と合わせて1,259問。1998〜2004年は全60問と当時の正答を取得できる公開掲載元を未発見のため未収録。

## 取得元と権利

- 2005〜2009年：翔泳社の公開問題PDFから `pdftotext -layout` で問題文・選択肢を抽出。
- 2010年：翔泳社PDFは画像主体のため、過去問ドットコムの画面上の問題文・選択肢を抽出。翔泳社掲載の公表正答PDFで当時の正答を確認。
- 2011〜2017年：ケアニュースの全分野テストから問題文・選択肢・掲載正答を抽出。過去問ドットコムの417問と文字差を比較（2011年2問、2012年1問は一覧に掲載なし）。
- 2014〜2017年：和歌山県の公式正答PDFで照合。2014年問39はケアニュースの1・4・5から公式の1・2・5へ訂正。
- 2011〜2013年：民間掲載正答を採用。公式正答との再照合は未完了。

問題ごとのURLとテキストSHA-256は `pre2018-import-audit.json`、掲載元間の差分は `pre2018-source-differences.json` に保存する。フィールド単位で別掲載元を採用した30問の実際の文言・採用理由は `scripts/pre2018-text-overrides.json` に保存する。元の取得元と採用元の両方をアプリの出典に表示する。

[試験センターの利用条件](https://www.sssc.or.jp/pastissues/index.html)に従い、公開されている試験問題と正答のみを利用する。各民間サイトの独自解説、広告、画像、画面デザイン、プログラム、電子データベース自体は配布しない。テキスト出題に原本の切り出し画像は必要としない。

## 品質・採点

全問の独立した二重校正と現行法への適合確認は未完了。`quality.json` の `textStatus: pending`、`secondReview: pending`、`lawStatus: not_reviewed` を維持する。掲載元間の一致や公式正答の照合は、原本に対する二重校正とは区別する。法改正注記を含む掲載サイトはあるため、差分を残して後続校正で確認する。問題文を推測で補完したり、現行法に合わせて問題・当時の正答を変更したりしない。

- 2005年問28：公表正答で採点中止。アーカイブに残し、通常出題から除外。
- 2006年問19：1・3・5のうち任意の2つ（1・3／1・5／3・5）を正答とする。
- 2009年問21：1・3／1・4／3・4を正答とする。
- 分類は既存のA/B/C分類への独自の暫定分類。試験当時の行政分類や現行法の妥当性を保証するものではない。
- 既存の2025年問題ID、版番号、概念ID、学習履歴のスキーマは変更しない。

## 再収集

Python 3、`lxml`、`curl`、Popplerの`pdftotext`が必要。

```sh
python scripts/crawl-pre2018.py --cache /tmp/care-exam-cache --output /tmp/pre2018-collected.json
```

キャッシュを使い、逐次取得・30秒タイムアウト・取得間隔を設ける。出力は採用前のステージングデータで、問題パックを自動上書きしない。再取得した文字差を照合し、採用理由を記録してからパックを更新する。正答・分類・品質状態は問題テキストと別のJSONで管理する。
