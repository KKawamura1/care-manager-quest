# 過去問の選択肢○×判定データ

## ファイル

- `data/choice-tf/choice-answers-2005-2025.json` — 問題IDごとに選択肢1〜5の真偽判定を保持します。

## 判定の意味

- `○`: 元の設問文脈で、選択肢の内容が正しい。
- `×`: 元の設問文脈で、選択肢の内容が誤っている。
- `not_convertible`: 採点中止などにより、有効な真偽判定がない。

`choiceAnswers` は選択肢1〜5の順です。カードには元の設問文も表示してください。単独では意味が決まらない選択肢も、設問文と合わせて判定します。

## 正答キーと選択肢の真偽

各問題の `correctChoiceTruth` は、公式正答に含まれる選択肢自体が真か偽かを表します。

| `correctChoiceTruth` | 正答キーに含まれる選択肢 | 正答キーに含まれない選択肢 |
| --- | --- | --- |
| `true` | `○` | `×` |
| `false` | `×` | `○` |
| `not_convertible` | 判定不能 | 判定不能 |

そのため、「誤っているもの」「正しくないもの」「不適切なもの」を選ぶ設問では `correctChoiceTruth: "false"` とし、正答キーを基準にしたラベルを反転します。単に「被保険者とならないもの」のように否定された条件への該当を問う設問は、否定表現があるだけで反転せず、設問文脈でその条件に当てはまる選択肢を `○` とします。

2005〜2025年の設問文を確認した範囲では、誤り・不適切な記述そのものを選ばせる設問は見つかりませんでした。現行データの変換可能な問題は `correctChoiceTruth: "true"` です。今後の追加では設問の指示を確認し、正答選択肢が偽なら `"false"` を設定してください。

正答は試験当時の公表・照合済みデータに基づき、現行法への適合性を示すものではありません。解説文はこのデータには含みません。

## 既存分類との分離

このデータは安定した問題IDと選択肢番号だけで参照し、知識カテゴリや概念IDを含みません。カテゴリ体系を変更しても○×判定を維持できます。

各レコードに `sourceReview` がある場合は、元データの転記・正答確認状態を引き継いでいます。レビュー状態は選択肢の真偽ラベルとは別に扱ってください。

## 対象と例外

- 2005〜2025年度、1,260問題ID、各5選択肢。
- 1,259問は○×に変換可能です。
- 2005年問28は採点中止のため `not_convertible` です。
