# 過去問の選択肢○×判定データ

## ファイル

- `data/choice-tf/choice-answers-2005-2025.json` — 問題IDごとに選択肢1〜5の判定を保持します。

## 判定の意味

- `○`: 元の設問に対する正答選択肢として、正答データに含まれる。
- `×`: 元の設問の正答選択肢に含まれない。
- `not_convertible`: 有効な正答がなく、選択肢を○×カードにできない。

`choiceAnswers` は選択肢1〜5の順です。カードでは元の設問文も表示してください。○×は選択肢単独の一般的な事実の真偽ではなく、元の設問への正誤を表します。正答は試験当時の公表・照合済みデータに基づき、現行法への適合性を示すものではありません。

## 既存分類との分離

このデータは安定した問題IDと選択肢番号だけで参照し、知識カテゴリや概念IDを含みません。カテゴリ体系を変更しても○×判定を維持できます。

各レコードの `sourceReview` がある場合は、元データの転記・正答確認状態を引き継いでいます。レビュー状態は選択肢の○×ラベルとは別に扱ってください。

## 対象と例外

- 2005〜2025年度、1,260問題ID、各5選択肢。
- 1,259問は○×に変換可能です。
- 2005年問28は採点中止のため `not_convertible` です。
- 解説文はこのデータには含みません。
