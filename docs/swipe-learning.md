# ○×スワイプ学習MVP

## 体験

冒険ホームまたはメニューの「○×学習」から、年度・知識分野を選んで最大20枚ずつ学習する。初期設定は全年度・全分野。右スワイプ／○ボタン／右キーが○、左スワイプ／×ボタン／左キーが×。縦方向・短い移動・キャンセルは解答しない。解答後は正答と判定根拠を確認して次へ進む。二重解答は受け付けない。元の設問文と選択肢本文は改変せず表示する。

## 変換と保留

mainのPR #21・#24・#25を前提とし、`data/choice-tf/choice-answers-2005-2025.json` の真偽を使用する。正答キーへの所属だけから直接○と決めない。`correctChoiceTruth=false` の設問では正答キー内を×とし、キー外を○とする。否定された条件を問う設問は文字列だけで反転しない。単独では意味の決まらない選択肢があるため、元の設問文を必ず添える。

アプリの2020年度ID `care_manager_2020_NNN` はそのまま維持する。分類・真偽データの `YYYY-NN` へは原データの年度・問番号で接続し、全5選択肢の番号・本文と試験当時の正答との整合を検証する。空本文、不完全な5択、判定欠落、判定不能、正答と一致しないラベル、許容正答パターンで真偽の一致しない選択肢は採用せず、`swipeCatalog.excluded` に理由を記録する。

## 細分類の範囲

共通知識体系179概念から、単一論点の問題の主概念を暫定的に引き継ぐ。関連概念がある問題、`needs_option_level_review`、主概念参照がない・無効な問題は、各選択肢を特定の概念へ推定割当てせず分類待ちに残す。元のstatus・revision・sourceReviewをカードに保持する。

この絞り込みは選択肢単位の確定した分類を意味しない。2025年度の現在の問題単位データは関連概念を持つため、同年度のカードは分類待ちで学習できる。選択肢単位の具体的な分類は #27。既存知識マップや過去の概念証拠を再集計せず、#23 を継続する。

## 解説

既存の○×登録データには解説がない。未検証の医学・制度上の説明を補作しない。選択肢の独自解説が登録されていれば表示し、未登録なら試験当時の正答キーとの対応と未登録表示を出す。原問題の全選択肢と、利用可能な原本画像・公式PDF・掲載元を確認できる。検証済みの1〜2文の独自解説・×の訂正は #28。

## 復習

- 誤答: 連続正解数を0へ戻し、1分後に復習。
- 正解: 連続正解数に応じて1・3・7・14・30・60日後。以降は60日。
- セット開始時: 期限が来た誤答、期限が来た正解、未学習の順。各グループで復習時刻の古いものを優先する。未学習は年度の新しいものから出す。
- 1セット最大20枚。今のセットは選択したカードで完了し、次のセットから新しく期限が来た復習を優先する。
- 真偽ラベル・問題版が変われば、以前の記録を保持したまま現行版の習熟を未学習として扱う。分類だけの変更では正誤習熟をリセットしない。

これは透明なMVPルールであり、医学・教育上の習熟度推定ではない。5択のXP・コンボ・概念習得へ加点しない。

## 保存と互換性

既存 `care-manager-quest:v1`（schema 2）と独立して、`care-manager-quest:swipe:v1`（schema 1）にカードごとの集約記録を保存する。元の5択データ・履歴・XP・途中クエストは変更しない。○×画面を他のタブへ切り替えても同じ20枚の位置と判定を保持する。ページ再読み込みでは未回答のセットを再開する代わりに保存済みの復習記録から次のセットを組む。

○×JSONは4MB以内。ID・版・回数・正解数・連続正解数・誤答回数・最終解答・正誤・日時を検証する。入力は内容確認後に明示的に置換する。破損履歴は自動上書きせず、元の文字列を回復用に書き出せる。保存領域へアクセスできない場合も既存画面を壊さず通知する。保存失敗時はメモリ内の記録を専用JSONで書き出せる。

デバイス間同期・複数タブの同時更新は #6 の対象。年度・分野の設定と未完了の○×セットはページ再読み込みをまたいで保存しない。

## 検証

- 全出題カードの本文・元設問・番号保持、全正答パターンとの真偽整合。2020年度300枚のID接続、採点中止・判定欠落・矛盾・誤りを選ぶ設問・否定条件の扱い。
- 混在・レビュー待ちの分類保留、参照整合、年度・細分野の絞り込み。
- 誤答優先と復習間隔、版変更、全6,289枚の保存往復、不正JSONと破損回復。
- iPhone 13相当のChromium/WebKit: 左右・短距離・縦方向の操作、ボタン・キーボード、20枚完走、再読み込み後の復習優先、JSON確認・取消・置換、保存領域のアクセス拒否、5択途中セッションの不変。
- ChromiumでCDPから実際のtouchStart/touchMove/touchEndを送る追加テスト。WebKitでは同じPointer Events処理をドラッグで検証し、CDP専用テストをskipする。実機iPhoneの指操作は未確認。

標準の型チェック・単体テスト・ビルド・全E2Eは既存のGitHub Actionsで実行する。ブラウザ画面とtraceはCI成果物に残す。

実装時のローカル結果: 型チェック成功、単体テスト40件成功、全ブラウザE2E51件成功・1件skip（Chromium専用CDPテストのWebKit側）。既存38件と新規13件が成功。日本語フォントで両ブラウザの画面を目視確認。ローカルWebKitは既存のブラウザ依存ライブラリを環境変数で読み込んで実行し、ホスト依存検証のみskipした。リポジトリのブラウザ設定・CIの依存導入は変更していない。
