# 選択肢単位の共通学習履歴

○×学習を正本とし、5択を「5枚の○×カードへの一括回答」として扱う。
両モードとも `PlayerState.learningEvents` に `cardId`, `revision`, `answer`, `mode`, `at`, `xp`, `bonusXp` を追記する。

## 評価

- JSTのカレンダー日付で**カードの最初の回答のみ**正誤評価・XPへ反映する。同日の2回目以降は練習として履歴には残るが評価もXPも0。モードをまたいでも共通。
- 学習レベルは直近5学習日の初回回答、重み1〜5（最新が5）。5回未満の不足分は古い側を不正解とする。
- 要復習度は最終評価日時からの経過日数÷目標間隔。目標間隔は学習レベル <30%=1日、<60%=3日、<90%=7日、その他14日。
- 知識マップは引き出しに割り当てられた**全カードの学習レベル平均**で習熟を表現（80%以上が習得）。要復習表示は期限到来カード割合で、経過だけで学習レベルを下げない。
- ○×正解10XP、誤答・わからない2XP。同日の評価済み回答は0XP。5択の全選択肢が確定可能かつ全問正答、同日未評価なら追加20XP。
- 5択の「選択した」は設問が正しいものを選ぶ形式なら○、誤ったものを選ぶ形式なら×に変換。確定不能な選択肢は共通学習履歴に記録しない。

## 保存

`care-manager-quest:learning:v3` の単一JSONとして保存、○×単独の保存領域は使用しない。
後方互換は切る。古いブラウザ保存領域を変更することなく新キーを使う。
記録画面のJSON書き出し/読み込みは両モード共通。

## 画面

○×はセット制限なし。元問題の別の選択肢は24時間待機し、新問題優先の出題候補と復習期限到来候補を混ぜて提示する。
回答結果のXPと5択・○×合計XPを表示し、知識マップも共通履歴から算出する。
