# 分類再設計の基本方針（基本テキスト準拠・検討中）

関連: [PR #68](https://github.com/KKawamura1/care-manager-quest/pull/68)、[分類仮説 v1.1](./taxonomy-v1.1.md)、[490概念→旧15中分類の棚卸し](./PR68_CONCEPT_TO_15_CATEGORIES.md)

> **方針の合意を記録する文書であり、新分類の確定版やデータ移行指示ではない。**
> PR #68の現行4大分類・15中分類と490概念のID、命題・学習履歴、アプリ挙動はこのコミットでは変更しない。
> 今後の中分類案・全命題の割当て結果を検証してから、正式な移行計画を策定する。

## 決定した設計方針

1. **専門家が編纂した既存教材の分類を原則として尊重する。** とくに長寿社会開発センター編集・発行『十訂 介護支援専門員基本テキスト』（2024年）の5編を大分類の**第一候補**にする。従来の独自4大分類・15中分類に固執しない。
2. **中分類は複数教材の実際の章立てと試験出題範囲を比較して検討する。** 基本テキスト、主要試験対策書、国の試験出題範囲の共通点を優先し、差異は明示する。単純な統計上の均等分割や恣意的な固定件数を目的にしない。
3. **最終的な目的は、過去問の選択肢に含まれる「正誤判定に必要な知識」を学びやすく一意に引き出せること。** 問題文の表面キーワード、設問の出題分野、主語の名詞だけで分類しない。設問の条件と命題の述語・判定根拠を参照する。
4. **教材の章立てと、アプリ内での正本の所在地を区別する。** 教材では教育上同じ話題が複数章に現れてもよいが、アプリでは原則として各命題・知識引き出しの正本を一か所にする。専門分野別の表示や関連知識への導線は別のタグ・関係で持てるようにする。
5. **現行データの分類結果を評価材料にする。** 490概念・6,346命題の分布、曖昧な境界、過度に一般的な概念、未レビュー分類を点検し、必要な場合に限って基本テキストの体系を調整する。分類件数の存在は、意味的な正しさの保証ではない。
6. **大分類・中分類から先に検討する。** 合意前に概念・属性IDを全面移行したり、本番の学習分類を切り替えたりしない。各段階で実データとの対応表と曖昧事例を示す。

## 大分類の第一候補（基本テキスト5編に準拠）

| ID（仮） | 大分類 | 主な対象 | 境界の考え方（今後検証） |
| --- | --- | --- | --- |
| 1 | 介護保険制度 | 制度・保険者、被保険者、認定、給付、保険料・財政、指定監督 | 事業所の人員・運営の**内容**と、行政による**指定・監督の手続**を区別 |
| 2 | ケアマネジメント | 介護支援の原則、アセスメント、計画作成、調整、評価 | ケアマネジメント**一般の技法**と、個別サービス事業所固有の運営基準を区別 |
| 3 | 介護保険サービス | 居宅・地域密着・施設・予防サービス等の内容、提供体制、施設・人員・設備・固有の運営基準 | サービス固有の要件をここに集める。医療系／福祉系を上位で機械的に分断しない |
| 4 | 高齢者保健医療の基礎知識 | 加齢、疾病・症状、身体機能、検査、保健医療の基礎、関連技術 | 疾患そのものの知識と、その疾患を対象とするサービスの固有基準を区別 |
| 5 | 高齢者福祉の基礎知識 | 相談援助・ソーシャルワーク、生活支援、権利擁護、福祉関連制度・資源 | 介護保険法上の給付・認定と、その他の福祉制度の知識を区別 |

名称・並び・下位区分は暫定。特に「支援原則」「介護技術」「専門職資格」「高齢者の住まい」「他制度との調整」は中分類の比較で境界を明文化する。

### 命題単位の分類例（仮）

| 問われている判定知識 | 大分類候補 |
| --- | --- |
| 特養のケアマネの配置人数 | 3 介護保険サービス |
| 特養の施設の設備・固有運営基準 | 3 介護保険サービス |
| 特養の指定権者や指定取消し手続 | 1 介護保険制度 |
| 介護保険の給付額・利用者負担 | 1 介護保険制度 |
| ケアプランのアセスメントの進め方 | 2 ケアマネジメント |
| 認知症の病態や薬理 | 4 高齢者保健医療の基礎知識 |
| 成年後見制度による権利擁護 | 5 高齢者福祉の基礎知識 |

**注:** これらの仕分け規則は当アプリ独自の「知識の正本」を設計するための暫定運用ルールであり、基本テキストの目次に載る個別命題の公式分類ではない。

## 試験の3分野は別メタデータで保持する

教材の学習体系は原則5大分類。一方、介護支援専門員実務研修受講試験の出題区分は「介護支援分野」「保健医療サービスの知識等」「福祉サービスの知識等」であるため、**5分類を試験の3分野と同一視しない**。出題年度ごとの試験区分に対応した学習が必要なら、独立した出題分野メタデータとする。

## 次の検討手順

1. 基本テキストの詳細目次と複数の試験対策書の章立てを収集し、**出典が確認できた範囲**だけを比較表にする。
2. 既存490概念と命題数を仮の5大分類・中分類候補へ対応づけ、未分類・多義・交差事例をレビューする。
3. 中分類ごとに**定義・含むもの・含まないもの・典型的な判定知識**を記述し、学習上のまとまりを検証する。
4. 大・中分類のレビューが固まった段階で、概念×属性（知識の引き出し）を正本として再割当てする移行PRを別途計画する。
