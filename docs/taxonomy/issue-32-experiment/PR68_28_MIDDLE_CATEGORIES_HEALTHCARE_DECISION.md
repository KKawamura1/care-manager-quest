# PR #68｜保健医療4.7の廃止・4.6再定義（5大分類・28中分類）

> **合意した中分類の設計方針を記録する文書。分類データの移行ではない。**
> [25中分類案](./PR68_25_MIDDLE_CATEGORY_REVISION_PROPOSAL.md)で新設した4.7「保健医療専門職・医療提供体制」を**廃止**し、4.6を「医療・介護の実践」に改称・拡張する。
> [大分類3の8中分類決定](./PR68_29_MIDDLE_CATEGORIES_SERVICE_DECISION.md)を前提に、全体は **5大分類・29中分類 → 5大分類・28中分類** とする。
> 旧24分類への[490概念の対応表](./PR68_CONCEPT_TO_24_CATEGORIES_PROPOSAL.csv)、命題・概念ID・知識の引き出し・アプリは本コミットでは変更しない。

## 1. 決定事項

- **4.7「保健医療専門職・医療提供体制」を廃止。**
- **4.6「医療・介護技術」を「医療・介護の実践」に改称。** ケアの実施技術だけでなく、医療・介護行為を行う専門職の役割・実施可能な行為など、実践に関係する判定知識を含める。
- 医師・看護師・薬剤師・医療機関という**主語だけで一括して4.6に入れない**。問題の判定に必要な知識を基準として4.6・4.4・大分類1・2・3・5などへ再配置する。
- 保健医療の中分類は以下の**6件**とする。

| ID（仮） | 名称 | 対象 |
| --- | --- | --- |
| 4.1 | 加齢・老年症候群 | 加齢変化、フレイル、転倒、褥瘡、低栄養など |
| 4.2 | 身体疾患・感染症 | 身体疾患の病態、特徴、感染症 |
| 4.3 | 認知症・精神疾患 | 認知症、MCI、せん妄、うつ病、精神疾患 |
| 4.4 | 症状・検査・薬剤 | 疾患横断的な徴候、検査・診断、薬理 |
| 4.5 | 生活機能・栄養・リハビリ | ICF、ADL、栄養、摂食嚥下、リハビリ |
| 4.6 | **医療・介護の実践** | 具体的な医療・介護行為、ケア技術、実施する専門職の役割、終末期ケア |

## 2. なぜ独立した4.7を廃止するか

旧24中分類の490概念対応表に明確に見つかる候補は次の通り。

| 概念（現行IDは保存） | 命題数 |
| --- | ---: |
| 死亡診断書の交付資格 | 10 |
| 医師・歯科医師 | 1 |
| 看護師 | 2 |
| 薬剤師 | 1 |
| 医療従事者の免許 | 1 |
| 医療機関（別IDで2概念） | 2 |
| 認知症疾患医療センター | 1 |
| **合計（概念名から抽出した候補）** | **18** |

以前の「**4.7は約28命題**」は、実際の再分類による確定件数ではなく、旧4.3等から周辺概念が移るとの概算。根拠が明確な抽出候補は18命題であり、**18件すべてが4.6へ移るとも限らない**。

旧4.6「医療・介護技術」は353命題という仮割当てだった。4.7廃止後の新4.6は数百命題規模になる見込みだが、**個別再割当て前に370〜380命題と確定扱いしない**。

専門職は独立した知識主題になる場合もあるが、介護支援専門員試験では、資格・職務・連携・サービスの基準・医療的行為等のさまざまな文脈に現れる。これを「専門職」の中分類へ集めると、判定知識が関連サービス・制度・実践から離れてしまう。

## 3. 分類境界・代表例

| 問われている判定知識 | 分類先の第一候補 | 注記 |
| --- | --- | --- |
| 死亡診断書を交付できる職種 | 4.6 医療・介護の実践 | 職務・行為の実施主体。ただし法律上の規律を中心に問う場合は別途照合 |
| 医療行為を実施できる資格・職種 | 4.6 医療・介護の実践 | 行為・実施主体の知識 |
| 検査・診断の手法、検査値 | 4.4 症状・検査・薬剤 | 医療行為一般の制度ではなく医学的評価 |
| 医療職の資格・登録の行政手続 | 関連する法制度（1または5を検討） | **介護保険固有の行政制度と混同しない** |
| 訪問看護事業所の人員配置や運営基準 | 3.2 訪問サービス | [大分類3の8中分類決定](./PR68_29_MIDDLE_CATEGORIES_SERVICE_DECISION.md)の新ID |
| 医療機関とケアマネの連携・調整方法 | 2.3 ケアプラン・実施・評価 | ケアマネジメントの過程・実践 |
| 医療機関の種類・制度上の位置づけ | 法制度／生活資源（1・5を含め再検討） | 施設名だけで4.6には置かない |
| 看護師が行う具体的な医療的ケア | 4.6 医療・介護の実践 | サービス固有の運営基準を問う場合は3 |

**注：** 上記は分類上の仮説であり、法的な資格要件や個々の過去問の正誤判定を新たに確認したことを意味しない。
