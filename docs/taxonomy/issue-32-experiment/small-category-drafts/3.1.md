# 3.1 サービス総論・共通基準：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 介護保険サービスの法定区分：居宅・施設・地域密着・予防、共生型
- 介護サービスの契約・利用開始：説明・同意、重要事項、提供拒否
- 介護サービスの記録・情報保護：保存、共有、守秘
- 介護サービスの安全・質管理：事故、衛生、虐待防止、業務継続
- 共通の人員・設備の考え方：常勤換算、兼務、共用、適用範囲
- 介護報酬の共通ルール：加算・減算の考え方、請求単位

### サンプルからの判断

2005問38-1は旧「居宅サービス」でも通所リハ固有の計画基準なので3.3候補。2005問40-2は施設計画の知識なので3.6候補。旧の広い分類をそのまま共通基準へ移さない。

共通の契約・記録・安全・人員設備・報酬を候補にする。各命題の横断適用を確認してから割り当てる。

## 境界・命題移行時の確認

複数サービスに実際に共通する知識のみ。サービス名不明の命題をここへ入れない。指定監督は1.5、給付対象は1.4。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
