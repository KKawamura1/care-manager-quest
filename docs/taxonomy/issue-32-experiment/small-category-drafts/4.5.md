# 4.5 生活機能・栄養・リハビリ：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 国際生活機能分類（ICF）：心身機能、活動、参加、環境
- ADL・IADL：定義、動作、機能評価
- 高齢者の栄養：栄養素、必要量、食事、栄養評価
- 摂食・嚥下機能：過程、反射、障害、評価・訓練
- 口腔機能：咀嚼、唾液、口腔乾燥、オーラルフレイル
- リハビリテーション・機能訓練：目的、方法、専門職、運動
- 姿勢・移動・関節機能：拘縮、バランス、動作、ボディメカニクス
- 福祉用具の適合・使用：身体機能との適合、移動補助、使用

### サンプルからの判断

2005問26-4は旧ICF概念にいるが、実際はパーキンソン病の症状の比較であり4.2候補。ICFの用語が原命題にあるかを確認し、旧IDに引きずられない。

## 境界・命題移行時の確認

機能・栄養・リハビリを扱う。低栄養という病態は4.1、食事介助・経管栄養管理は4.6、サービスの通所リハ基準は3.3。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
