# 4.1 加齢・老年症候群：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 加齢による身体・心理の変化：予備力、感覚、恒常性、適応
- 高齢者の疾病・老年症候群の特徴：多病、非典型、生活への影響
- フレイル・サルコペニア：定義、危険因子、評価、予防
- 廃用症候群：原因、機能低下、予防
- 転倒・転落：危険因子、環境、予防
- 褥瘡：原因、病態、評価、予防・ケア
- 脱水・電解質異常：原因、所見、水分管理
- 低栄養・栄養障害：原因、病態、栄養不良の兆候
- 高齢者の排尿・排便障害：失禁、便秘、原因、排泄機能
- 高齢者の睡眠障害：加齢、睡眠リズム、環境、予防

### サンプルからの判断

フレイル、褥瘡、脱水は原因・所見・予防等を持つまとまりとして独立させる。

## ③ 照合して採用する仮案

老化一般に加え、原因・予防・ケアがまとまる症候群を分ける。脱水と電解質、フレイルとサルコペニアは当面まとめて種類を属性化。

| 仮小分類ID | 概念名 | 属性・引き出しの例 |
| --- | --- | --- |
| `4.1.aging` | 加齢による身体・心理の変化 | 予備力、感覚、恒常性、適応 |
| `4.1.gerontology` | 高齢者の疾病・老年症候群の特徴 | 多病、非典型、生活への影響 |
| `4.1.frailty` | フレイル・サルコペニア | 定義、危険因子、評価、予防 |
| `4.1.disuse` | 廃用症候群 | 原因、機能低下、予防 |
| `4.1.falls` | 転倒・転落 | 危険因子、環境、予防 |
| `4.1.pressure_ulcer` | 褥瘡 | 原因、病態、評価、予防・ケア |
| `4.1.dehydration` | 脱水・電解質異常 | 原因、所見、水分管理 |

## 境界・命題移行時の確認

身体の老化・症候群を扱う。認知症・せん妄・うつは4.3、栄養摂取の一般知識は4.5、薬剤が原因であることを問うなら4.4。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
