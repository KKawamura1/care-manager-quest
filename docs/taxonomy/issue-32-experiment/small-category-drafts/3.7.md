# 3.7 地域密着型サービス：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 夜間対応型訪問介護：対象、夜間対応、体制、運営
- 定期巡回・随時対応型訪問介護看護：対象、一体・連携型、体制、運営
- 小規模多機能型居宅介護：登録、通い・訪問・泊まり、人員、計画
- 看護小規模多機能型居宅介護：登録、看護・介護、医療連携、人員
- 認知症対応型共同生活介護：対象、共同生活、人員、設備、計画
- 認知症対応型通所介護：対象、単独・併設・共用型、人員、設備
- 地域密着型通所介護：定員、人員、設備、運営
- 地域密着型介護老人福祉施設：対象、定員、人員、設備、計画
- 地域密着型特定施設入居者生活介護：対象、定員、人員、運営
- 地域密着型サービス固有の共通原則：地域との関係、利用範囲、運営推進

### サンプルからの判断

夜間、看護小規模多機能、グループホームは提供形態が違っても法定の地域密着型へ集約できる。

## 境界・命題移行時の確認

法定の地域密着型を訪問・通所・入居より優先。行政上の指定監督は1.5、地域支援事業は1.6。介護予防型は制度区分属性で保持。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
