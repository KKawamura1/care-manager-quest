# 3.2 訪問サービス：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 訪問介護：対象、身体介護・生活援助、人員、計画、運営
- 訪問入浴介護：対象、入浴方法、人員、設備、運営
- 訪問看護：医師の指示、看護内容、人員、計画、運営
- 訪問リハビリテーション：対象、内容、人員、計画、運営
- 居宅療養管理指導：職種別提供内容、情報提供、運営

### サンプルからの判断

身体介護／生活援助、訪問入浴の職員体制、訪問看護の提供内容を各サービスの属性にできる。

## ③ 照合して採用する仮案

サービスは制度上別の対象なので分ける。人員・設備・提供内容ごとに小分類を増やさず各サービスの属性とする。

| 仮小分類ID | 概念名 | 属性・引き出しの例 |
| --- | --- | --- |
| `3.2.visiting_care` | 訪問介護 | 対象、身体介護・生活援助、人員、計画、運営 |
| `3.2.visiting_bath` | 訪問入浴介護 | 対象、入浴方法、人員、設備、運営 |
| `3.2.visiting_nurse` | 訪問看護 | 医師の指示、看護内容、人員、計画、運営 |
| `3.2.visiting_rehab` | 訪問リハビリテーション | 対象、内容、人員、計画、運営 |
| `3.2.home_medical` | 居宅療養管理指導 | 職種別提供内容、情報提供、運営 |

## 境界・命題移行時の確認

一般の訪問サービスに限定。夜間対応・定期巡回・小規模多機能は3.7、直接的な看護・介護技術は4.6。予防型は同概念の制度区分属性で区別。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
