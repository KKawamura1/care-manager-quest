# 4.3 認知症・精神疾患：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 認知症の病態・症状：原因疾患、中核症状、BPSD、経過
- 軽度認知障害（MCI）：定義、評価、経過
- 認知症に固有のケア：本人理解、環境、BPSDへの対応
- せん妄：急性経過、原因、鑑別、対応
- うつ病・気分障害：症状、鑑別、治療
- 統合失調症・妄想性障害：症状、治療、生活支援
- アルコール関連障害：依存、離脱、支援
- 神経症・不安関連障害：不安、身体症状、対応

### サンプルからの判断

せん妄とうつは認知症から分離できる。2012問31-1は薬剤の剤形を判定するため、認知症の題材でも4.4へ移す候補。

## 境界・命題移行時の確認

認知症等に固有の病態・ケアを扱う。成年後見・虐待法は5.3、認知症地域事業の制度は1.6、一般的意思決定技法は2.1／5.1。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
