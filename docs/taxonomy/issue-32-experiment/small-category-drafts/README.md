# 全28中分類の小分類仮案

中分類ごとに①知識体系の候補→②PR68の少数サンプル→③採用する仮案の順で整理。1.2と1.3はPR68の例をそのまま継承。全中分類の案を先にコミットし、その後に命題分類を行う。
