# 3.8 居宅介護支援・介護予防支援：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 居宅介護支援事業所：基本方針、人員、管理者、運営
- 居宅サービス計画の法定作成基準：訪問、面接、会議、同意、交付、見直し
- 居宅介護支援の記録・契約：説明、契約、情報提供、保存
- 居宅介護支援費：算定、加減算、利用料、請求
- 介護予防支援事業所：配置、委託、運営、基本方針
- 介護予防サービス計画の法定作成基準：作成、評価、会議、同意、記録

### サンプルからの判断

法定計画作成の基準が旧事業所概念に多く含まれる。事業所・計画・記録契約・報酬へ対象を分ける。

## 境界・命題移行時の確認

事業所・法定計画・契約記録・報酬を対象として分け、人員や期間は属性にする。汎用アセスメント・計画技法は2、指定権者は1.5。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
