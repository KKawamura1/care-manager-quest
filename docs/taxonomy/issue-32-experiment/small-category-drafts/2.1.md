# 2.1 基本理念・役割・倫理：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- ケアマネジメントの自立支援・尊厳：本人中心、残存能力、社会参加
- ケアマネジメントの意思決定支援：意向、説明・同意、選択
- ケアマネジメントの公正中立：利益相反、公平、サービス選択
- ケアマネジメントの情報倫理：守秘、同意、情報共有
- 介護支援専門員の専門的役割：職務、守備範囲、連携責任
- ケアマネジメントのチーム支援：多職種、協働、スーパービジョン

### サンプルからの判断

自己決定・情報共有・ケアマネの立場を別の論点にする。旧意思決定支援の一般相談事例は5.1との境界を確認する。

## ③ 照合して採用する仮案

自立・意思決定・公正・情報倫理を分け、一般の相談援助との文脈を境界で定める。登録・更新は候補から除外。

| 仮小分類ID | 概念名 | 属性・引き出しの例 |

| `2.1.independence` | ケアマネジメントの自立支援・尊厳 | 本人中心、残存能力、社会参加 |

| `2.1.role` | 介護支援専門員の専門的役割 | 職務、守備範囲、連携責任 |

## 境界・命題移行時の確認

ケアマネの職務に結び付く原則に限定する。一般の相談援助原則は5.1、介護支援専門員の試験・登録制度は1.5。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
