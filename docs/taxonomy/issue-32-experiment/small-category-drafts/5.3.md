# 5.3 権利擁護・虐待防止：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 法定後見（後見・保佐・補助）：対象、類型、代理・同意・取消権
- 任意後見：契約、開始、監督、権限
- 成年後見の申立て・監督：請求者、家裁、選任、報告
- 日常生活自立支援事業：対象、契約、援助内容、実施主体
- 高齢者虐待の類型・発見：身体・心理・経済、放棄、発見
- 高齢者虐待の通報・対応：通報、市町村調査、保護、養護者支援
- 身体拘束の防止：例外要件、代替、記録
- 権利擁護の推進制度：成年後見利用促進、認知症基本法

### サンプルからの判断

後見開始の請求は後見手続、虐待発見時の通報は虐待対応、契約による生活支援は日常生活自立支援。

## 境界・命題移行時の確認

権利を支える法制度と虐待対応を扱う。一般の援助倫理は5.1、地域支援事業としての後見利用支援は1.6。法定後見の3類型は属性で比較。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
