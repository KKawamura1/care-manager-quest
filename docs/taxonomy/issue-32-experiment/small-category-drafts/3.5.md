# 3.5 福祉用具サービス：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 福祉用具貸与：種目、人員、選定・計画、点検
- 特定福祉用具販売：種目、人員、販売・計画、説明
- 福祉用具の貸与・販売選択制度：対象種目、選択支援、説明、制度時点

### サンプルからの判断

種目の貸与／販売区分はサービス属性にできる。吸引器の例は用具種目の給付対象性と一般の給付条件の境界事例。

## ③ 照合して採用する仮案

貸与・販売・選択制度を分ける。製品種目や人員配置は属性として保持する。

| 仮小分類ID | 概念名 | 属性・引き出しの例 |
| --- | --- | --- |
| `3.5.rental` | 福祉用具貸与 | 種目、人員、選定・計画、点検 |
| `3.5.sale` | 特定福祉用具販売 | 種目、人員、販売・計画、説明 |
| `3.5.selection_system` | 福祉用具の貸与・販売選択制度 | 対象種目、選択支援、説明、制度時点 |

## 境界・命題移行時の確認

貸与・販売の事業基準と種目を扱う。支給限度・給付請求全般は1.4、身体に合う用具の使用・選択は4.5。住宅改修費は1.4。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
