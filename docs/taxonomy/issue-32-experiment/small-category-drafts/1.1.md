# 1.1 制度総論・被保険者：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 介護保険の目的・基本理念：目的、自立・尊厳、国民の努力義務
- 介護保険の保険者：保険者、共同処理、特別区
- 第1号被保険者資格：年齢、住所、取得・喪失
- 第2号被保険者資格：年齢、医療保険加入、取得・喪失
- 住所地特例：対象施設、保険者、転入転出
- 適用除外：対象施設、資格の扱い
- 介護保険制度改正：改正の内容、施行時期、経過措置
- 介護保険制度の統計：認定者数、利用者数、給付費の推移

### サンプルからの判断

資格と住所地特例を別の対象にする。制度統計は認定・給付の「手続」と混ぜない。

## ③ 照合して採用する仮案

被保険者資格を第1号・第2号に分ける。制度改正・統計は年度を概念IDにせず属性に保持する。

| 仮小分類ID | 概念名 | 属性・引き出しの例 |
| --- | --- | --- |
| `1.1.purpose` | 介護保険の目的・基本理念 | 目的、自立・尊厳、国民の努力義務 |
| `1.1.insurer` | 介護保険の保険者 | 保険者、共同処理、特別区 |
| `1.1.first_insured` | 第1号被保険者資格 | 年齢、住所、取得・喪失 |
| `1.1.second_insured` | 第2号被保険者資格 | 年齢、医療保険加入、取得・喪失 |
| `1.1.address` | 住所地特例 | 対象施設、保険者、転入転出 |
| `1.1.exclusion` | 適用除外 | 対象施設、資格の扱い |
| `1.1.reform` | 介護保険制度改正 | 改正の内容、施行時期、経過措置 |
| `1.1.statistics` | 介護保険制度の統計 | 認定者数、利用者数、給付費の推移 |

## 境界・命題移行時の確認

保険料賦課・徴収は1.2、認定時の原因疾病要件は1.3。認定者数等の集計統計は行政手続そのものと区別してここに集約する。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
