# 2.3 ケアプラン・実施・評価：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- ケアプランの構成・目標：目標、課題との整合、計画書
- ケアプラン作成の過程：原案、説明・同意、確定、変更
- サービス担当者会議：目的、参加、開催、意見調整
- サービス・社会資源の調整：資源選択、役割分担、連携
- モニタリング・再評価：実施状況、達成度、再アセスメント
- 退院・退所・生活移行支援：引継ぎ、医療との連携、切れ目ない支援

### サンプルからの判断

会議・モニタリングを分離できる。2005問19-1は支給限度額自体が判定対象か、計画の適切性が判定対象かを移行時に再確認する。

## ③ 照合して採用する仮案

計画の対象・作成過程・会議・調整・評価・生活移行を分ける。担当職種や実施頻度は属性にする。

| 仮小分類ID | 概念名 | 属性・引き出しの例 |
| --- | --- | --- |
| `2.3.care_plan` | ケアプランの構成・目標 | 目標、課題との整合、計画書 |
| `2.3.planning` | ケアプラン作成の過程 | 原案、説明・同意、確定、変更 |
| `2.3.service_meeting` | サービス担当者会議 | 目的、参加、開催、意見調整 |
| `2.3.coordination` | サービス・社会資源の調整 | 資源選択、役割分担、連携 |
| `2.3.monitoring` | モニタリング・再評価 | 実施状況、達成度、再アセスメント |
| `2.3.transition` | 退院・退所・生活移行支援 | 引継ぎ、医療との連携、切れ目ない支援 |

## 境界・命題移行時の確認

汎用的な計画・調整・評価技法を扱う。訪問頻度・会議省略条件など法定作成基準は3.8、各サービスの個別計画は当該3.x。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
