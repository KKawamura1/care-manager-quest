# 3.3 通所サービス：小分類の仮案

> 設計案。5大分類・28中分類を固定。全命題の再分類前に作成した案であり、サンプル確認は真偽・当時法令の意味レビューではない。

## ① 知識体系から立てる候補

一次資料で分野の対象・過程・法定サービスを確認し、次を候補とした。公式教材の見出しを転載した分類ではなく、当アプリの設計案。

- 通所介護：対象、提供内容、人員、設備、計画
- 通所リハビリテーション：対象、内容、人員、設備、計画
- 療養通所介護：対象、体制、医療連携、出題当時区分

既存件数は旧分類の機械的集計。新しい中分類への確定件数ではなく、網羅抽出もしていない。

### サンプルからの判断

通所介護の目的、通所リハの会議、療養通所の計画を別サービスの属性にできる。療養通所は出題時区分を保持。

## ③ 照合して採用する仮案

通所介護と通所リハを分ける。療養通所の年代差は独立の境界事例として残す。

| 仮小分類ID | 概念名 | 属性・引き出しの例 |
| --- | --- | --- |
| `3.3.day_care` | 通所介護 | 対象、提供内容、人員、設備、計画 |
| `3.3.day_rehab` | 通所リハビリテーション | 対象、内容、人員、設備、計画 |
| `3.3.medical_day` | 療養通所介護 | 対象、体制、医療連携、出題当時区分 |

## 境界・命題移行時の確認

地域密着型通所・認知症対応型通所は3.7。療養通所介護は2016年前後で法定区分が変わるため出題時点で3.3と3.7を判断する。

候補の判定に複数対象が必要な命題は、中心知識を確認してから配置する。マッチ用語だけで確定しない。出題時点の制度区分・廃止制度を保持し、現行制度を過去問へ遡及適用しない。属性未整理や既存の未レビュー状態は移行で消さない。
