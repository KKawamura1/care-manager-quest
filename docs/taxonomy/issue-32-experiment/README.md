## 配置ルール

各命題に、概念主語・属性・候補を含む経路を記録し、Issue #32 の4つの上位分類を共通のIDと名称で保持しています。

| ID | 上位分類 |
|---:|---|
| 1 | 人の健康と生活 |
| 2 | 支援の考え方と方法 |
| 3 | 支援の提供体制 |
| 4 | 社会保障の仕組み |

選択肢原文と設問文は各レコードにそのまま持ち、分割後の文章は `proposition` に記録します。選択肢の真偽、正答、解説、現行法との一致は判定していません。`primary_path` は選択した場合の1経路です。`ambiguous` は主経路を空にして2つ以上の候補を残し、`unmapped` は経路を割り当てず `proposed_nodes` 等に不足概念を記録します。

## 状態と出典情報

- `assigned`: 主経路を1つ選べた。
- `ambiguous`: 複数の主経路候補が残る。主経路は空。
- `unmapped`: 現在の仮説ツリーに当てはまらない。主経路は空。
- `needs_source_review`: 原文または設問文だけでは経路を選べない。
- `source_review_required`: OCR、原文比較、二次レビュー、当時の法令等の確認が別途残るかを表す。分類状態とは独立している。

既存パックの分類・レビュー状態、除外フラグ、原文ソースや品質情報をレコードの追加フィールドとして保存しました。年度ごとに既存データのキー名が異なるため、追加フィールドは元のキー名を保っています。2005年度第28問は既存の採点除外フラグを保持したまま、分類対象として記録しています。

2025年度は `imports/2025-all60/*.b64` を既存インポートスクリプトで復元した60問を唯一の入力として使用しました。復元データの SHA-256 は `badd92f316d751be0eb8414cfb4139f533e57a8186a0f53ab07302017de8161a` です。通常の2025年度パックにある25問の範囲を重複収録していません。

## ファイル

- `propositions/YYYY.jsonl`: 年度別の命題分類。UTF-8 JSONL。
- `difficult-cases.jsonl`: `ambiguous` と `unmapped` のみを抽出したレビュー用一覧。原文、分類理由、候補、出典フラグも保持。
- `existing-concept-crosswalk.csv`: 既存 `taxonomy-v2.json` の179概念すべてを列挙。旧分類は問題単位、新分類は選択肢・命題単位のため、共起件数と候補経路を示すだけの暫定クロスウォークであり、概念の移行や統合は提案していません。
- `manifest.json`: 年度別・状態別の件数、検証範囲、出典メモ。
- `checksums.json`: 収録ファイルのサイズとSHA-256。

## 検証と残課題

全21年度で60問・各300選択肢を確認し、レコードキー重複0、選択肢ごとの命題番号連番を確認しました。2005〜2016年度は原文パックと全選択肢のテキストを機械比較し、3600選択肢すべて一致しました。2025年度は復元後の全60問・300選択肢と元データのハッシュを確認しています。

以下は分類上の未解決例です。全件は `difficult-cases.jsonl` にあります。

- `2005-15` 選択肢2 命題2（ambiguous）: ケアマネジメントにおける計画作成方法と、居宅介護支援事業者に課される運営上の義務の双方に読める。

v1.1では、(1) 制度・サービス固有のルールと一般的な相談援助技法が一つの選択肢に併記される場合の主語選択、(2) 介護保険と他制度の給付調整の境界、(3) 疾病・症状の知識と具体的支援方法の境界、(4) 複合文を命題に分割する基準を、実例を使って明文化するのが有効です。出典レビューが残る項目は該当フラグを解消してから最終的な分類経路を確定してください。

この実験は新規ドキュメントだけを追加します。既存の問題文、正答、解説、学習履歴、製品動作、179概念のtaxonomyは変更していません。
