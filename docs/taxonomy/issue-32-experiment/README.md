# Issue #32: 選択肢・命題単位の知識分類実験

このディレクトリはIssue [#32](https://github.com/KKawamura1/care-manager-quest/issues/32) の仮説分類データです。2005〜2025年度の全問題・全選択肢を、原文に結び付いた命題単位で整理しました。`hypothesis-v1.0` はレビュー用の提案であり、確定済みの分類体系や正誤判定ではありません。

## 2020〜2024年度の統合分類レビュー（2026-10-11）

PR [#46](https://github.com/KKawamura1/care-manager-quest/pull/46)（2020）、[#44](https://github.com/KKawamura1/care-manager-quest/pull/44)（2021）、[#42](https://github.com/KKawamura1/care-manager-quest/pull/42)（2022）、[#43](https://github.com/KKawamura1/care-manager-quest/pull/43)（2023）、[#47](https://github.com/KKawamura1/care-manager-quest/pull/47)（2024）の年度別修正を、**PR #33 の現行ブランチ上で合成**した。各年度60問・300選択肢の知識の主語・属性と命題の文脈を再点検した。

- 2020年度：301命題。名詞句35件の命題を補完し、曖昧6件を解消。
- 2021年度：301命題。社会保険方式の複合選択肢1件を分割。
- 2022年度：300命題。300選択肢の中心概念と分類を修正。

- 2024年度：304命題。複合選択肢4件を分割し、6問の省略述語を補完。判断の原記録は `review-decisions-2024-part1.json` / `part2.json` に保持。
- **実験全体**：6,345命題（6,300選択肢）。分類状態は assigned 6,265件、ambiguous 80件。意味レビュー済み2,113命題（2018・2019・2025年度分も含む）。
- 元の `source_text`・設問文・正答・学習履歴・既存179概念は未変更。履歴フラグは維持し、OCR・選択肢の真偽・当時法令の確認は未実施。旧クロスウォークは初回分類のスナップショット。

## 2026-10-11 2025年度の命題・分類再レビュー（PR33からの差分）

PR33で一度再分類した2025年度の300選択肢を対象に、**命題そのものが単体で学習可能な知識になっているか**と**知識の主語に沿った分類先になっているか**を点検した。

- 設問文への依存が残る命題を**112選択肢**で補完。特に第12・13・15・19・22・39問は、短い名詞句・項目名を「何に含まれるか／何の徴候か」という独立した肯否判定可能な命題にした。
- 入浴の清潔保持と生理的効果（第27問肢1）、ソーシャルワークの人権尊重と社会的包摂（第47問肢1）を別命題に分割（**300選択肢→302命題**）。
- **42選択肢**で知識対象・属性・経路を再点検（類似属性を精密化したものを含み、すべてが誤分類だったという意味ではない）。例：パーソン・センタード・ケア→支援原則、認知症初期集中支援チーム→支援機関、臨死期の徴候→身体徴候、看護師の薬剤処方→専門職の業務権限、地域密着型サービス共通基準の制定権限→制度運営。
- 原文 `source_text`、設問、正答、法令上の真偽、出典・OCRフラグは変更していない。命題補完・分割の旧表現は `proposition_revision` に残した。追加分類レビューは `classification_revision.additional_reviews` に保持。
- 2025年度の分類上の難例を勝手に `assigned` へ追加することはしていない。分割によるレコード数の増加はレビュー件数にも反映する。
- 他年度の命題データ、既存179概念、学習アプリは変更していない。crosswalkは引き続き初回分類時点のスナップショットである。

## 2026-10-11 分類品質修正

初回分類には、本文中のキーワードに引っ張られて中心概念・属性を取り違える系統的な誤りがあった。認知症施策推進計画を病態、通所介護の基本方針を報酬・費用、認定調査票の項目を口腔機能としていた。

- 2025年：60問・全300選択肢の経路を設問と選択肢の文脈から再分類。旧ambiguousの4件も分類先を設定。
- 2024年：21問・105選択肢を再分類。残る195件は未レビュー。
- 2018年：明白な2件を再分類。
- 合計407レコードで経路を変更（確定した誤分類数ではなく、粒度統一も含む）。各レコードのclassification_revisionに旧状態と旧経路を保存。
- 残る5,928命題は今回意味的にレビューしておらず、正しい分類と保証できない。assignedは単一の経路が選ばれた状態という意味に過ぎない。
- 2025年問1の社会保険一般については、介護保険固有ルールと混同しないため新しい社会保険一般ノードを仮置きした。構造への正式追加は別のレビューが必要。

**重要：existing-concept-crosswalk.csvは初回分類時のスナップショットであり、この407件の分類経路変更による共起件数の再計算は未実施。最新分類の集計には使用しないこと。** 旧179概念との対応はそもそも問題単位の共起であり、一対一の移行表ではない。

選択肢の正誤・試験当時の法令・OCR校正は本修正の対象外であり、別途レビューが必要。

## 配置ルール

各命題に、概念主語・属性・候補を含む経路を記録し、Issue #32 の4つの上位分類を共通のIDと名称で保持しています。

| ID | 上位分類 |
|---:|---|
| 1 | 人の健康と生活 |
| 2 | 支援の考え方と方法 |
| 3 | 支援の提供体制 |
| 4 | 社会保障の仕組み |

選択肢原文と設問文は各レコードにそのまま持ち、分割後の文章は `proposition` に記録します。選択肢の真偽、正答、解説、現行法との一致は判定していません。`primary_path` は選択した場合の1経路です。`ambiguous` は主経路を空にして2つ以上の候補を残し、`unmapped` は経路を割り当てず `proposed_nodes` 等に不足概念を記録します。

## 状態と出典情報

- `assigned`: 主経路を1つ選べた。
- `ambiguous`: 複数の主経路候補が残る。主経路は空。
- `unmapped`: 現在の仮説ツリーに当てはまらない。主経路は空。
- `needs_source_review`: 原文または設問文だけでは経路を選べない。
- `source_review_required`: OCR、原文比較、二次レビュー、当時の法令等の確認が別途残るかを表す。分類状態とは独立している。

既存パックの分類・レビュー状態、除外フラグ、原文ソースや品質情報をレコードの追加フィールドとして保存しました。年度ごとに既存データのキー名が異なるため、追加フィールドは元のキー名を保っています。2005年度第28問は既存の採点除外フラグを保持したまま、分類対象として記録しています。

2025年度は `imports/2025-all60/*.b64` を既存インポートスクリプトで復元した60問を唯一の入力として使用しました。復元データの SHA-256 は `badd92f316d751be0eb8414cfb4139f533e57a8186a0f53ab07302017de8161a` です。通常の2025年度パックにある25問の範囲を重複収録していません。

## ファイル

- `propositions/YYYY.jsonl`: 年度別の命題分類。UTF-8 JSONL。
- `difficult-cases.jsonl`: `ambiguous` と `unmapped` のみを抽出したレビュー用一覧。原文、分類理由、候補、出典フラグも保持。
- `existing-concept-crosswalk.csv`: 既存 `taxonomy-v2.json` の179概念すべてを列挙。旧分類は問題単位、新分類は選択肢・命題単位のため、共起件数と候補経路を示すだけの暫定クロスウォークであり、概念の移行や統合は提案していません。
- `manifest.json`: 年度別・状態別の件数、検証範囲、出典メモ。
- `checksums.json`: 収録ファイル（自身を除く）のサイズとSHA-256。

## 検証と残課題

全21年度で60問・各300選択肢を確認し、レコードキー重複0、選択肢ごとの命題番号連番を確認しました。2005〜2016年度は原文パックと全選択肢のテキストを機械比較し、3600選択肢すべて一致しました。2025年度は復元後の全60問・300選択肢と元データのハッシュを確認しています。

v1.1では、(1) 制度・サービス固有のルールと一般的な相談援助技法が一つの選択肢に併記される場合の主語選択、(2) 介護保険と他制度の給付調整の境界、(3) 疾病・症状の知識と具体的支援方法の境界、(4) 複合文を命題に分割する基準を、実例を使って明文化するのが有効です。出典レビューが残る項目は該当フラグを解消してから最終的な分類経路を確定してください。

この実験は新規ドキュメントだけを追加します。既存の問題文、正答、解説、学習履歴、製品動作、179概念のtaxonomyは変更していません。
