# PR #68｜小分類再編 第1回：1.2 保険料・財政（仮案）

> **設計案／未適用**。対象は新設計 5大分類→28中分類の **1.2「保険料・財政」** のみ。
> 既存概念ID、命題の分類正本、正規化ロジック、アプリ表示は**変更していない**。
> 既存概念の命題件数は現行4→15分類による機械的集計値であり、新1.2への確定所属件数ではない。

## 目的と方法

490概念すべてをボトムアップで眺めるのではなく、**中分類単位で (1) その分野の知識体系から小分類候補を先に立て、(2) 既存概念と少数の実際の命題を見て、(3) 両者を照合して小分類を設計する**。
小分類＝知識の対象（概念）、極小分類＝その概念について正誤判定で問う属性（知識の引き出し）とする。「徴収方法」「負担割合」「設置主体」等は原則として概念を無制限に増殖させず属性として保持する。

参照する親分類：[TARGET_TAXONOMY_5X28.md](./TARGET_TAXONOMY_5X28.md)／母数：[PR68_CONCEPT_PROPOSITION_COUNTS.csv](./PR68_CONCEPT_PROPOSITION_COUNTS.csv)。

## ① 制度の知識体系から考えた候補

- **介護保険の財源構成**：給付費の保険料／公費負担の仕組み、国・都道府県・市町村の負担。施設等給付と居宅給付の相違、年度による割合の変化は属性。
- **第1号被保険者保険料**：保険料率・所得段階・設定主体・計画期間、特別徴収／普通徴収、減免・徴収猶予・滞納。賦課・徴収手続はこの概念の属性。
- **第2号被保険者保険料・介護納付金**：医療保険者による徴収、介護納付金・支払基金を通じた資金の流れ、総報酬割など。被保険者資格の一般論は1.1。
- **調整交付金**：普通調整交付金／特別調整交付金、保険者間の財政調整。普通・特別は当面**属性として区別**する（必要に応じ後から分割）。
- **財政安定化基金**：設置主体、財源、貸付／交付と適用要件。
- **介護保険特別会計・財政運営**：市町村の特別会計、財政収支・基金等の運営。サービス事業計画そのものの策定・記載事項は1.6。
- **地域支援事業の財源**：総合事業と包括的支援事業等の費用負担の差。事業内容・実施要件は1.6。

この7件は、教科書の公式見出しを転記したものではなく、試験の判定知識を分離するための**アプリ固有の暫定設計**。費用負担割合・保険料率などの数値は試験当時と現在で変わり得るため、概念名やIDへ数値・年度を埋め込まない。

## ③ 照合後に採用する小分類（暫定ID）

| 新小分類ID（案） | 名称 | 判定属性の例 |
| --- | --- | --- |
| `1.2.funding` | 介護保険の財源構成 | 公費と保険料の割合、国・地方の負担、施設等給付の違い |
| `1.2.first_premium` | 第1号被保険者保険料 | 賦課主体、算定、所得段階、普通・特別徴収、減免、滞納 |

| `1.2.adjustment_grant` | 調整交付金 | 普通・特別の区分、交付理由、算定要素、交付主体 |
| `1.2.stabilization_fund` | 財政安定化基金 | 設置、負担、貸付／交付、財政不足要件 |
| `1.2.accounting` | 介護保険特別会計・財政運営 | 特別会計、収支・予算、積立・基金 |

選び方：**制度的に異なる対象は別概念**にする一方、「普通徴収／特別徴収」「普通／特別調整交付金」「設置主体」「負担割合」等は同じ対象の**属性**として持つ。小分類をサービス名や出題の見出しで作らない。原則として概念×属性で一つの引き出しを構成する。

## 境界規則・今後のレビュー

1. 1.1「制度総論・被保険者」：年齢や資格要件そのものは1.1。保険料負担を判定する場合のみ1.2。
2. 1.4「保険給付・利用者負担」：給付制限・受給方法・利用者負担の条件は原則1.4。保険料の徴収・猶予そのものは1.2。
3. 1.5「行政運営・指定監督」：支払基金／医療保険者の**組織・権限**と、保険料・納付金の**資金経路**を区別。
4. 1.6「地域支援事業・事業計画」：事業の内容・実施主体・計画策定は1.6。**財源負担**を問うときは1.2。
5. 複数の知識を主張する命題や当時制度の違いが絡む命題は、概念名だけで自動確定せず、正誤判定に必要な知識と出題年度でレビュー。今回の各割当ては**仮説**。
6. 新IDは**予約・反映済みではない**。既存IDの削除・統合や正本変更は、命題単位の移行表と属性・引き出し整合性を確かめた後に別作業で実施。

**今回の完了範囲**：1.2 のトップダウン候補、既存6概念（162命題）の対応候補、境界・追加候補、命題サンプル、7小分類の暫定案を記録。**未実施**：1.2関連全命題の洗い出し・再割当て、その他27中分類、アプリ・CI変更。
