# 知識の種類ごとの年度横断レビュー

2005〜2024年度の1,236命題を、同じ知識概念に属する命題をまとめて読む方法で個別レビューした。各命題の本文を確認して概念・属性を選び、文脈依存の代名詞や事例は設問文も確認した。年度順に一問ずつ処理する方法から、サービス基準・認定・給付・相談援助などの知識ごとの処理へ変更し、判断の比較と反映をまとめて行った。分類を単語で推測するルールの追加だけで意味レビュー済みにしていない。

## 対象と結果

| --- | ---: |

| 要介護認定・保険給付・生活保護・成年後見 | 299 |
| 相談援助・ケアマネジメント | 295 |

| 合計 | 1,236 |

既存の538件から、判定知識の意味レビュー済みは1,774件へ増えた。未レビューは4,572件。追加分では概念ラベルを719件変更し、4大分類間で111件を移動した。既に意味レビュー済みの命題と既存の個別引き出し判断は保持した。

引き出し数の増加は、未整理の大きな分類から異なる知識を分けた結果である。要レビュー件数と意味レビュー未実施件数は別の指標であり、混同しない。

## 追跡と検証

各命題に判定知識、旧分類、追加履歴を保存し、個別引き出し判断に入力フィンガープリントと `crossyear-knowledge-batches` を記録した。設問文・原文・命題・分割・年度・出典・正答関連の既存情報・校正フラグ・当時法令確認フラグは変更していない。変更前後の全年度データでこれらの保持を照合した。

固定された旧件数や「この引き出しには未整理の命題が必ず残る」という検査を、実データの集計整合性と全共有引き出しの保守的なレビュー状態の検査へ更新した。一つの命題をレビューしても、同じ引き出しの未確認命題が自動承認されないことを検査する。代表例は正規化IDだけでなく、実際の学習カードへの反映も回帰検査する。

全年度の正本・集計・チェックサム・原文同期・判定知識記録・ID整合性を検証した。型チェック、52ユニットテスト、ビルドが成功。関連するスマホ操作E2EはChromiumの16件とWebKitの14件が成功し、WebKitではChromium専用の2件をスキップした。

今回のレビューは、分類する知識の特定を対象とする。過去問の真偽、原文の二重校正、当時法令への適合性の確認を完了したという意味ではない。
