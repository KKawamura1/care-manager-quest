# 知識分類の設計仕様：5大分類・28中分類

> **固定の設計正本。PR68派生ブランチで命題・表示へ仮移行済み。** 詳細・残る要確認は [再分類結果](./RECLASSIFICATION_5X28.md) を参照。大分類・中分類のID・名称は不変。
> 対象：介護支援専門員試験の2005〜2025年度、1,260問・6,346命題、正規化された490概念。
> **現行データは4大分類・15中分類の設計**（実際のアプリのツリーは4大分類→概念）。「5大分類・24中分類」は以前の一時的な仮割当てであり、現行の4大分類の下に24中分類があるわけではない。
> **移行後の目標：5大分類→28中分類→概念（小分類）→属性／知識の引き出し（極小分類）**。

## 1. 移行後の大分類

| ID | 大分類 | 判定知識の対象 |
| --- | --- | --- |
| 1 | **介護保険制度** | 被保険者、保険料、認定、給付、行政、地域支援事業 |
| 2 | **ケアマネジメント** | 支援原則、アセスメント、計画、実施・評価 |
| 3 | **介護保険サービス** | サービス固有の内容・人員・設備・運営基準 |
| 4 | **高齢者保健医療** | 疾病・症状、健康状態、医学的評価、医療・介護の実践 |
| 5 | **高齢者福祉** | 相談援助、権利擁護、生活保障、住まい・地域資源 |

大分類の考え方は『介護支援専門員基本テキスト』の「介護保険制度／ケアマネジメント／介護保険サービス／高齢者保健医療の基礎知識／高齢者福祉の基礎知識」を基本にする。ただし以下の**28中分類は当アプリ用の設計**で、教材の公式な区分そのものではない。

## 5. 衝突回避の優先規則

1. **設問の題材・サービス名でなく、正誤判定に必要な中心知識を分類する。** 単一の広い概念名が複数の知識を抱えている場合は命題単位で見直す。
2. **介護保険制度（1）とサービス固有知識（3）を区別する。** 指定権者・行政監督・給付全般は1。特養の人員配置、訪問看護事業所の固有運営基準は3。法令で定められていることだけを理由に1へ集めない。
3. **ケアマネジメントの実践（2）と事業所固有基準（3.8）を区別する。** アセスメント・計画・モニタリングの汎用技法は2。
4. **介護保険サービスは、地域密着型（3.7）、居宅介護支援・介護予防支援（3.8）を優先する。** それ以外を訪問（3.2）・通所（3.3）・短期入所（3.4）・福祉用具（3.5）・入居施設（3.6）で分ける。地域密着型通所介護は3.7、特定施設入居者生活介護は3.6、地域密着型特養は3.7。
5. **サービス総論・共通基準（3.1）は複数サービスに実際に横断適用される知識のみ。** 未分類命題の受け皿にしない。旧仮割当ての「約107命題」は広い概念名からの概算であり、共通知識として確認済みではない。独立分類としての妥当性は命題レビューで検証する。
6. **医療・介護の実践（4.6）に職種名だけで集めない。** 医療・介護行為や役割は4.6、検査・薬剤は4.4、事業所の固有基準は3、ケアマネとの連携技法は2。医療職の資格・登録手続は根拠法令と判定知識から個別に判定する。
7. **福祉（5）は相談援助・福祉法制度・生活資源を扱う。** 一般的な相談援助は5.1／5.2、成年後見・虐待防止は5.3、生活保護・障害福祉等は5.4、住まい・地域資源は5.5。高齢者向け住まいの一般知識と、介護保険サービスである特定施設の固有基準は別。
8. **出題当時と現行の制度区分を区別する。** 療養通所介護、旧・介護予防訪問介護／通所介護などは出題年度の制度を確認し、現在の区分を機械的に遡及適用しない。
9. **正本は知識の引き出し（概念×属性）。** 一つの判定知識は原則一か所に置き、試験出題分野（介護支援・保健医療・福祉）、訪問／通所の提供形態、関連サービスは別タグ・関連概念として扱う。
