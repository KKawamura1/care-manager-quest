## 分類境界の暫定判断

- **法令上のサービス区分**をサービス領域の中分類3.1／3.2／3.3／3.4に使用。例えば、地域密着型介護老人福祉施設は「3.2 地域密着型サービス」に仮置きする（施設形態のタグは別に検討）。
- **制度共通の行政手続・指定権限**は1.5、**サービス固有の人員・設備・運営基準**は3。後者が法律上定められていることだけを理由に1へは移さない。
- **ケアマネジメント一般のアセスメント、計画、モニタリング**は2。居宅介護支援・介護予防支援**事業所固有の基準**は3.4。
- **一般的な相談援助、家族・集団・地域援助**は5.1。**医学的評価**は4.3、**栄養・ADL・リハビリ**は4.4、**直接的な医療・介護技術**は4.5。
- **介護保険法上の認定・給付・財政・行政**は1。**成年後見・虐待防止**は5.2、**生活保護・障害福祉・他の社会保障制度**は5.3。
- 特養の人員配置→3.3、特養の指定権者→1.5、特養の看取りケア技術→4.5（該当命題の判定知識が何かで区別）。

## 注意が必要な設計上の問題

1. **「介護支援専門員の資格・職務」(2.5)に対し、他の専門職の資格・職務の専用中分類がない。** 介護職員を5.1、医師・看護師・薬剤師を4.3に暫定配置したが、適切な中分類の増設や再配置が必要かもしれない。
2. **「住まい・社会資源・地域生活」(5.4)に医療機関や支援機関を仮置きしている。** サービス提供体制、地域支援事業との境界と、24分類を維持すべきか再検討する。
3. **幅広い概念は命題内に複数の判定知識を含む可能性がある。** 例:「介護保険制度」「相談援助」「支援技術」「介護保険サービス・施設」。中分類を1つ仮置きしたことで内包する全命題が適切になったわけではない。
4. **暫定概念175件と15分類外1件の旧IDを変更していない。** 新分類が適切でも、概念の正規化・統合・引き出しの確認は別作業。
5. **給付・利用者負担とサービス固有報酬、福祉制度と保険制度の境界**は命題の述語に基づき見直す必要がある。
6. **既存の4大分類は命題IDに埋め込まれていることがある。** この対応表は移行前のIDを保持したまま新パスを提案しており、IDプレフィックスから新分類を推測してはならない。
