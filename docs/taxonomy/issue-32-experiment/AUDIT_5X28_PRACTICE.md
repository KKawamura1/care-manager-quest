# 4.6 医療・介護の実践：分類監査

命題の判定に必要な知識よりも、旧分類の広い名称・命題内の単語・事例の場面が優先され、別の知識が同じ小分類に混在していた。年度正本の `taxonomy_assignment` を個別に修正し、判定対象と変更前の所属・属性・要確認状態を記録した。監査IDは `pr70-practice-2026-10-12`。

## 対象と確認方法

- 基準はPR70の `400b782`。ローカル `b43a3b8` とGitHub側のソースツリーは `bfd56792d43aa9784f802e7e188f01b94ed5906d` で一致。
- 4.6の要確認265命題を全16小分類に分け、命題・属性・既存の判定知識をスクリーニング。明確な変更対象は設問条件も確認して個別に判断した。
- 4.6の確認不要扱い181件から、各16小分類の命題ID順の最初と最後を選び32件を確認。これは層別の端点抽出であり、無作為標本ではない。
- リスクが見つかった「終末期」「職種の行為」「救命」「排泄」「口腔」「食事」の確認不要扱い66件へ拡張。最初の標本と12件重複する。死亡診断書の同一設問の残り3件も確認。確認不要扱いの確認対象は合計89件。
- Codexによる分類監査。人間の承認や、全命題の正誤・医学的妥当性・出題当時の法令照合を意味しない。スクリーニングだけで残りの要確認を解除しない。

## 残る確認

4.6には要確認186件が残る。ワクチンの予防知識と疾患知識の境界、酸素・人工呼吸・吸引の細分、病態と具体的ケアの境界などを精査する。必要な小分類追加・分割は知識の混在を根拠に検討し、件数だけでは決めない。

確認不要扱いにも誤配置・誤属性が存在したため、フラグだけを品質保証に使わない。次の4.2、1.5、1.6でも、要確認命題と確認不要扱いの双方を確認する。本監査の11件を全体の誤り率に外挿しない。
