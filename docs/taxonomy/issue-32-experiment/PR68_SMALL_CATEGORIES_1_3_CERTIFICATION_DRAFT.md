## 方法

1. 制度の流れ（申請→認定調査・主治医意見書→一次判定→介護認定審査会→認定・更新等）から、**先に小分類候補をつくる**。
2. PR #68 の490既存概念から関係するものを抽出し、2005〜2008年度の命題を**少数**確認する。
3. 制度的な対象が異なるものは小分類を分け、単なる項目・基準・期間・担当権限などは、その概念について問われる**属性（極小分類）**とする。

参考にした一次資料は末尾参照。年によって変わる有効期間・調査委託・審査基準は、今回の小分類名に埋め込まない。

## ① 制度知識から立てた小分類候補

- **要介護・要支援状態と認定区分**：認定の趣旨、要支援／要介護状態、区分、疾病の重さと介護の手間の違い。
- **認定の申請**：申請先、申請者、申請代行、添付物、申請から認定までの手順、転入時の認定手続。
- **認定調査**：基本調査、特記事項、実施・委託主体、調査員、調査の対象・項目。
- **主治医意見書**：医師への依頼・作成、意見書の内容、利用場面、主治医がいない場合。
- **一次判定と認定基準時間**：要介護認定等基準時間の算出・対象行為、コンピュータ判定、区分への対応。
- **介護認定審査会と二次判定**：組織、委員、合議体、審査資料、判定の手続・変更・付帯意見。
- **認定の効力・有効期間**：認定結果の通知、効力の発生、期間、認定結果の位置づけ。
- **更新・区分変更・取消し**：更新申請、状態の変化に伴う変更、職権変更・取消し、特例。
- **第2号被保険者の特定疾病と認定要件**：認定に必要な原因疾病の条件、該当性の判断。疾病の医学的病態そのものとは区別。

仮候補は**9件**。申請・認定結果・更新／変更を最初から一つの巨大概念にまとめず、制度上のステップを分離する。

## ③ 照合後の小分類（採用する暫定案）

| 新小分類ID（仮） | 新小分類名 | 属性／極小分類の例 |
| --- | --- | --- |
| `1.3.care_levels` | 要介護・要支援状態と認定区分 | 目的・基準、区分、要支援2／要介護1の境界 |
| `1.3.application` | 要介護・要支援認定の申請 | 申請先、申請代行、添付書類、転入時手続 |
| `1.3.assessment_survey` | 認定調査 | 基本調査、特記事項、実施主体、委託・調査員 |
| `1.3.physician_opinion` | 主治医意見書 | 意見書の内容、依頼主体、作成・利用、主治医不在 |
| `1.3.primary_judgment` | 要介護認定等基準時間・一次判定 | 対象行為、時間算定、判定材料・方法 |
| `1.3.review_board` | 介護認定審査会・二次判定 | 委員・合議体、判定・変更、付帯意見 |
| `1.3.validity` | 認定の効力・有効期間 | 結果通知、効力発生、期間、期間設定 |
| `1.3.renewal_change` | 認定の更新・区分変更・取消し | 更新申請、変更・取消し、例外・職権 |
| `1.3.specified_diseases` | 第2号被保険者の特定疾病と認定要件 | 特定疾病該当性、原因疾病の条件、確認手続 |

**設計上のポイント**：

- 「認定調査」と「一次判定」は分ける。前者は人が行う情報収集、後者は調査結果等を用いた判定。
- 「主治医意見書」を認定調査・二次判定に埋没させない。独立の作成主体・記載事項を問う命題がある。
- 「介護認定審査会」と「介護保険審査会」は名前が似ても**別の機関**。前者は1.3、処分への審査請求は原則1.5。
- 「要介護認定等基準時間」は時間の算定対象・考え方がまとまって問われるため、まず一次判定と同じ概念にする。ただし概念単位の命題が十分にまとまれば、後から切り分けられる。
- 状態区分の一般的な要件と、第2号被保険者に固有の**原因疾病**の要件は別概念にする。

## 隣接する分類との境界・保留事項

1. **1.1 制度総論・被保険者**：第1号・第2号の被保険者資格は1.1。第2号が要介護認定を受けるための原因疾病要件は1.3。疾病の病態・診断知識なら4.2/4.4も検討。
2. **1.4 保険給付・利用者負担**：要介護度に応じた給付費・支給限度額は1.4。区分の**認定基準**は1.3。
3. **1.5 行政運営・指定監督**：`4.1.administration.appeals`「介護保険の審査請求」（49命題）は介護保険審査会の制度であり、認定を判定する介護認定審査会とは混同しない。認定処分への審査請求でも、問われているのが不服申立て制度なら1.5。
4. **2.2/2.3 ケアマネジメント**：利用者の生活課題アセスメントやケアプラン作成は、行政による要介護認定の認定調査・判定とは別。
5. **統計概念（11命題）**：認定者数、要介護度構成比などは手続ではない。属性・クロスカッティングタグとして扱うか、`1.3.certification_statistics` を追加すべきかは命題確認後に判断。**今回は未決定として保留**。
6. **年代差**：2005〜2008年の認定区分、委託範囲、有効期間等の数値・権限は現行と一致するとは限らない。試験当時の制度を、現在の法令・運用に遡及適用しない。
7. **暫定ID・命題再割当て**：既存 `4.1.certification` の296命題を名称だけで一括変換せず、中心の判定知識を見て分配する。今回の新IDは**提案であり、実データにはまだ存在しない**。
