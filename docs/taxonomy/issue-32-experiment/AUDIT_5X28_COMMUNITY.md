# 1.6 地域支援事業・事業計画：分類監査

旧介護予防事業や市町村計画まで「包括的支援事業」にまとめられ、基本チェックリストの質問項目がアセスメントに、地域医療介護総合確保基金が在宅医療介護連携に入っていた。設問で問われる制度的な対象と属性を確認し、地域支援事業全体・各事業・事業計画の境界を整理した。

基準コミットは `9a25395`、監査IDは `pr70-community-2026-10-12`。数値はこの監査反映時点の比較。最新値は [現行分類集計](./RECLASSIFICATION_5X28.md) を参照。

### 設問条件の扱い

事業への所属を問う設問は、設問で指定された事業体系の「事業構成・実施内容」へ置く。例えば「任意事業に地域ケア会議推進事業が含まれるか」は、会議の機能ではなく任意事業の範囲を知る必要がある。誤った候補の名称だけを見て別事業の実施基準へ移さない。

一方、具体的な事業の機能・役割・実施主体が判定対象なら、その事業へ置く。生活支援コーディネーターの機能は生活支援体制整備事業、在宅医療介護連携の取組は当該施策へ分類する。複数命題に分かれている選択肢は、各命題の制度を分ける。

### 旧制度と現行制度

旧特定高齢者施策・一次／二次予防は、新しい一般介護予防とは別の小分類に置く。旧総合事業と総合事業は同じ概念内で「旧総合事業」の属性範囲を明示し、2010年の介護予防ケアマネジメントには「旧介護予防事業」を保持する。後者の概念名を「地域支援事業の介護予防ケアマネジメント」へ広げ、旧制度を現行の第1号介護予防支援事業へ遡及させない。原文と正答は変更しない。

## 補った5小分類

| ID | 名称 | 分ける理由 |
| --- | --- | --- |
| `1.6.framework` | 地域支援事業の体系・共通運営 | 全体の構成・利用料を包括的支援だけへ押し込まない |
| `1.6.legacy_prevention` | 旧介護予防事業（特定高齢者・一次／二次予防） | 旧対象者・事業内容を一般介護予防と分ける |
| `1.6.plan_framework` | 介護保険事業計画の基本指針・共通原則 | 国の指針と両計画共通の知識を片方の計画へ偏らせない |
| `1.6.health_welfare` | 介護保険法の保健福祉事業 | 地域支援事業の任意事業とは別の制度枠 |
| `1.6.life_support` | 生活支援体制整備事業 | コーディネーターの機能を医療連携・認知症施策と分ける |

既存の任意事業の名称から「関連事業」を外し、保健福祉事業を分離した。固定5大分類・28中分類のID・名称は保持。現段階で5〜6命題の小分類もあり、数を増やすために対象の異なる知識を統合しない。
