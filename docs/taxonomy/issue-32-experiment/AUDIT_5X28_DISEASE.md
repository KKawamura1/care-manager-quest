# 4.2 身体疾患・感染症：分類監査

疾患名に引っ張られ、疾患横断の検査、感染防護の実践、介護保険の認定条件、制度上の手続が疾患の小分類へ混在していた。また、原因・感染経路・治療・予防・経過を「病態・症状」にまとめている命題があった。判定対象と設問条件を読み、年度正本の所属・属性・根拠を更新した。

基準コミットは `51e3a5b`、監査IDは `pr70-disease-2026-10-12`。本書の数値はこの監査反映時点の比較で、最新値は [現行分類集計](./RECLASSIFICATION_5X28.md) を参照。

## 対象と確認の範囲

4.2の全351命題をスクリーニングした。内訳は要確認230件、確認不要扱い121件。抜き取りから全件へ対象を広げ、疾患固有の知識、疾患横断の知識、具体的な介助・感染防護、制度条件の境界を確認した。判断の更新対象は設問条件も用いて個別に確認し、疾患群へ統合される具体的な疾患名は属性の限定に保持した。

Codexによる分類監査である。所属・属性について判断できることと、命題の真偽・医学的妥当性・当時法令・文字校正を検証することは別であり、後者の状態は変更していない。人間が全件を承認した状態ではない。

276命題の分類判断を更新した。所属変更70件（4.2内の変更8件、他中分類への移動62件）、属性変更220件で、両者は重複する。既存配置の個別確認と要確認解除も含むため、276件すべてが誤配置だったという意味ではない。

変更前に確認不要扱いだった46件にも所属・属性等の修正が必要だった。元の要確認230件のうち226件を分類について解決し、4件は追加確認を保持。さらに確認不要扱いから1件を要確認へ戻した。残る5件のうち2件は他中分類へ移動したため、4.2の残件3と全体の減少225は一致しない。

誤った疾患・症状の組合せを述べる命題も、命題が真であるかのように分類せず、設問が判定させる疾患の知識へ置く。例えば脊髄小脳変性症と失語症の組合せは、失語という語だけで脳血管疾患へ移さない。

疾患固有のワクチンによる予防効果は4.2の「予防」、防護具・消毒・咳エチケットなどの実践は4.6、予防接種法や定期接種の制度要件は5.4に分けた。疾患名を含むだけで感染症の病態へ置かない。
