# 2025年度の判定知識レビュー

2025年度の全60問・300選択肢・302命題について、設問文と各命題を読み、正誤判定に必要な概念・属性を個別に記録した。2025-27/1と2025-47/1の命題分割を含め、302件すべてに `knowledge_target_review` と個別引き出し判断を追加した。

## 変更例

| 選択肢 | 以前の分類 | 判定知識による分類 |
| --- | --- | --- |
| 2025-25/4 | 個別事例への対応 | グループホームの利用対象・要件：認知症のない人への適用 |
| 2025-29/2 | 通所リハビリテーション | 介護予防通所リハビリテーションの利用対象・要件 |

事例問題でも、施設の法定利用要件が決定的ならその施設へ配置する。一方、本人・家族の意思尊重やアセスメントが問われる命題は支援方法へ配置する。誤った記述の対象を正しい答えの用語に置換せず、その記述を判定する知識に分類した。

指定・監督、制度上の権限、情報公表項目、法定事業構成は社会保障の仕組みに保持した。特定サービスの人員・設備・計画・運営は提供体制に保持し、サービス名や職種名の出現だけでは決めていない。

## 範囲と追跡

- 年度正本の変更は2025年度のみ。302命題のうち、主語となる概念ラベルを122件変更し、4大分類間の移動は7件。
- 302件の個別引き出し判断を追加し、以前の91件を保持。判定知識の意味レビューは236件から538件へ増加し、残り5,808件。
- 全年度合計の要レビュー命題は3,168件から3,043件、属性未整理は2,066件から1,951件へ減少。これは正規化の課題数であり、意味レビュー未実施件数とは別。
- 新たに「診断・治療の基本」「ACP」「一般介護予防事業」の概念を登録。ACPを終末期ケア全体と区別し、一般介護予防事業を地域支援事業全体と区別した。語彙の一致だけで未レビュー命題を意味レビュー済みとしない。
- 各命題の旧分類と既存の修正履歴を保持。個別引き出し判断の入力フィンガープリントにより、後から本文・命題・概念・属性・経路を変更した場合に再レビューを要求する。
- 本文・設問・命題分割・正答・年度・出典情報・校正フラグ・当時法令確認フラグを保持した。今回の意味レビューは、記述の真偽や当時法令への適合性を確定するものではない。

## 検証

全年度の構造・判定知識記録・引き出しID・原文同期・集計・チェックサムの既存チェックを実行。アプリのテストでは2025年度の300カードがレビュー済みとして生成されること、および疾病・介護予防・専門職の職務範囲・サービス計画などの代表例が実際の学習カードへ反映されることを検査する。

型チェック・51ユニットテスト・ビルドは成功。関連するスマホ操作E2EはChromiumの16件、WebKitの14件が成功し、WebKitではChromium専用の2件をスキップした。WebKitの実行に必要な `libGLESv2` をローカルに展開し、ライブラリパスを指定して実行した。

本番分類は年度JSONLから生成されるため、`npm run prepare:questions` で変更をアプリへ取り込む。
