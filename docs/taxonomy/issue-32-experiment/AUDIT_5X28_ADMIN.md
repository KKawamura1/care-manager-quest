# 1.5 行政運営・指定監督：分類監査

国保連の機関名だけで苦情処理やサービス事業運営まで審査支払へ分類し、情報公表制度を一般的な行政権限へまとめていた。また「指定」という語を含む事業所の提供義務・報酬・人員・計画まで指定監督に入り、審査請求の対象が期限などの属性になっていた。命題の判定対象に沿って所属と属性を更新した。

基準コミットは `43dbdaa`、監査IDは `pr70-admin-2026-10-12`。本書の数値はこの監査反映時点の比較。最新値は [現行分類集計](./RECLASSIFICATION_5X28.md) を参照。

## 対象・判断の範囲

1.5の全443命題を確認した。内訳は要確認188件・確認不要扱い255件。設問条件と既存の判定知識を用い、個別の制度的対象と、行政主体・機関名だけの仮配置を分けた。厚生労働省の介護保険法・苦情処理制度資料・情報公表制度の説明を、制度的対象を区別する参考にした。

Codexによる分類監査であり、原文・命題・正答・当時法令・既存の意味レビューの検証状態は変更しない。現在の法令を過去問へ遡及適用して正答を変更していない。人間が全件承認した状態ではない。

## 追加した小分類

`1.5.nhi_federation`「国保連の組織・法定業務」を追加した。国保連の第三者行為求償、共同電算処理、サービス事業・施設運営、他機関との業務の区別を扱う17命題を配置。これらを審査支払の受け皿へ押し込むと知識が混在するため、介護保険法第176条の業務区分と既存命題に基づいて補った。

審査支払・審査委員会は `1.5.payment_review`、苦情処理は `1.5.complaints`、指定監督や資格登録、支払基金の交付金等は各制度的対象に置く。5大分類・28中分類のID・名称は維持した。

## 要確認を保持した1件

2008-13/c3/p1「利用者からの苦情を受け付け，サービス提供事業者に対する指導・助言及び立入検査を行う。」は、苦情処理上の指導助言と強制的立入検査の権限が一命題に複合している。主所属を苦情処理へ変更し、指定監督との境界・命題分離の検討を要確認として記録した。変更前は確認不要扱いだった。
