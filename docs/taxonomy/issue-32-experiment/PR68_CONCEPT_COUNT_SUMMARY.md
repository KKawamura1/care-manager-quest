## 再集計・検算

```sh
node --experimental-strip-types scripts/report-issue32-concept-counts.mjs --check
node --experimental-strip-types scripts/report-issue32-concept-counts.mjs --write
```

`--check` は命題IDの重複、正規化IDと明示IDの一致、命題数・概念数・保存CSVの一致を検算する。 `--write` はデータ変更時にCSVを再生成する。基準値6,346／490／1,629は現スナップショット用。

**注意：分類結果の集計であり、命題の真偽・法改正・OCR・意味分類の再レビューは実施していない。**
