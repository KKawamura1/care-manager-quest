# 知識分類フレームワーク v1.1（実験仮説）

関連: [Issue #35](https://github.com/KKawamura1/care-manager-quest/issues/35)、[Issue #32](https://github.com/KKawamura1/care-manager-quest/issues/32)、[PR #33](https://github.com/KKawamura1/care-manager-quest/pull/33)

> 本書はv1.0の分類実験結果から作った**改訂仮説**。1,260問・6,335命題が正しく分類済みという意味ではない。元問題・正答・既存179概念・学習履歴は変更しない。

## 分類目的

目標は、関連する知識が一か所でまとまって思い出せる**概念主語の木**を作ること。

例えば「特養のケアマネ配置数」は `3→介護保険施設→特養→人員配置→介護支援専門員`。「特養の看護職員配置数」「老健のケアマネ配置数」も近い階層に置く。ケアマネの**登録移転**は施設基準と別に `3→専門職→介護支援専門員→資格・登録`。

## v1.1のトップと枝

1. **人の健康と生活**：状態／生活条件
   - **1.1 加齢・疾病・病態**：老年症候群、認知症、脳血管疾患、パーキンソン病、糖尿病ほか。疾病の下に原因・病態／その疾病固有の症状・合併症／検査・治療／固有のケア。
   - **1.2 症状・徴候・検査**：特定疾患によらない身体所見、検査値の解釈、共通リスク（CRPと炎症の対応など）。
   - **1.3 生活機能**：ICF、ADL・IADL、社会参加。
   - **1.4 生活背景**：本人、家族、住環境、地域、経済状況、生活統計。
2. **支援の考え方と方法**：汎用の方法／技法
   - **2.1 支援原則・倫理**：尊厳、自立支援、自己決定、権利擁護。
   - **2.2 相談援助**：面接・傾聴・援助関係・意思決定支援。
   - **2.3 ケアマネジメント**：アセスメント、ケアプラン、社会資源選択・調整、担当者会議、モニタリング。
   - **2.4 支援技術**：食事・排泄・移動、医療・看護、リハビリ、福祉用具活用、住環境調整、家族支援、ACP。
3. **支援の提供体制**：サービス・施設・住まい・担い手の固有知識
   - **3.1 介護保険サービス**：居宅、地域密着、施設（特養・老健・介護医療院）、居宅介護支援、介護予防支援、介護予防サービス。
   - **3.2 高齢者の住まい**：サ高住、有料老人ホーム、軽費老人ホーム、養護老人ホーム等。施設サービスは3.1を正本として参照のみ。
   - **3.3 専門職**：介護支援専門員、看護師、介護福祉士等。資格／登録／更新／業務／倫理。
   - **3.4 支援機関**：地域包括支援センター、社協、福祉事務所、医療機関等。
   - **3.5 物的・地域資源**：福祉用具、住宅設備、インフォーマルサービス、地域活動。
4. **社会保障の仕組み**：公的な保障・財源・統治
   - **4.1 介護保険制度**：理念・国民の努力義務／被保険者資格・適用除外・住所地特例／要介護認定／保険給付（住宅改修費・他制度との給付調整等）／保険料・財政／国・自治体の権限・審査支払・指定監督／地域政策。
   - **4.2 その他の法律・制度**：認知症基本法・施策推進計画／医療保険・障害福祉・生活保護・老人福祉・年金・成年後見・虐待防止等。

## 統一テンプレート

- **施設・サービス**：定義と目的 → 対象と提供内容 → 人員配置（職種別）→ 設備 → 運営 → 報酬 → 例外。
- **専門職**：定義と役割 → 資格と登録・更新 → 業務 → 倫理。
- **疾病**：原因・病態 → 固有症状 → 検査・診断・治療 → 固有ケア。
- **保険・法制度**：目的・対象 → 主体・権限 → 要件・手続 → 給付・費用・例外。

## 分類の決定規則（レビューで必ず使用）

1. 構文上の主語でなく、**正誤を判断するために取り出す中心知識**を分類する。設問文と選択肢を併読する。
2. 疾病の状態と、その疾病を対象にした法律・政策は区別（「認知症基本法」→4.2、「認知症の病態・BPSD」→1.1）。
3. 特定サービスの定義・提供内容・人員・運営上の**固有ルール**は3。そのサービス名が単に登場するだけの汎用支援技法は2。
4. 特定職種そのものの資格・登録・更新・責務は3.3。特養内の職種別必要人数は3.1の特養の人員配置。
5. 住宅改修のケア技法は2.4、住宅設備という資源は3.5、**住宅改修費の給付要件・限度**は4.1→保険給付。
6. 疾病名が中心の「疾患—症状」の対応は1.1疾病内。CRP等の疾患非特定の検査解釈は1.2。
7. 被保険者の資格・適用除外は4.1→被保険者資格。他制度の名前が登場しても移動しない。
8. 事業所の固有運営基準は3、介護保険制度に**共通する**行政・指定監督・支払制度は4。
9. 必要な複数命題を分割する。名詞だけの選択肢は設問の述語を補った命題と原文を別に保持。「候補として提示された」だけを学習命題にしない。
10. 真偽・試験時点の法令・OCR原文確認は別フラグ。曖昧・分類不能は強制一意化しない。原文や正答を書き換えない。

## 機械可読な概念ID

隣接する `taxonomy-v1.1.json` の `nodes` を、**改訂仮説の固定IDと親子関係**の正本とする。`primary_path` 文字列の自由生成は正式な概念登録ではない。実験レコードは `primary_node_id` を持てるが、未レビュー行に一律付けない。

- `status: assigned` は**エージェントが候補を選んだ**という意味で、手動検証済みではない。
- `classification_review: {version, reviewer, basis}` は実際に見直した行のみ付与する。
- 未収録の詳細概念は `proposed_nodes` で申請し、既存nodeを勝手に別名で作らない。
- 給付・住まい・疾病・職種間の参照は `related_concepts` で持ち、同一事実の正本を複製しない。
- 既存179概念・問題ID・学習履歴の移行は本PRの対象外。これらは専用のレビューを経て決定。
