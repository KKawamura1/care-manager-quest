# Care Manager Quest：2005〜2019年度の多年度知識分類 v3

## 対象・前提
- GitHub `KKawamura1/care-manager-quest` の PR #21 (`feat/pre2018-published-questions`) を確認。2005〜2019年度の15年分、各60問を対象とします。
- 2005年問28は試験の採点中止問題。分類対象には残しますが `isPlayable=false` です。
- **2018年と2019年を含みます。2019年は10月の本試験であり、2020年3月の再試験を含みません。**
- 2005〜2017は `src/data/packs/pre2018/{year}/questions.json` と `classifications.json`、2018・2019は `src/data/packs/{year}/questions.json` と `classifications.json` の設問と既存タイトルを確認。
- 2020〜2025の360問は前回作成済みのv2ドラフトを統合したものです。今回再分類・再校正していません。

## 設計
- 正本の知識体系は既存の `taxonomy-v2.json`（179概念、A/B/C階層）。概念を年度ごとに増殖させず、同じ話題を同じIDに集約しました。
- 問題ID（`YYYY-NN`）、正答、原文、画像、プレイ履歴、XPは一切変更しません。
- `question-concepts-2005-2019.json` は追加900件（プレイ可能899件）の分類のみを含みます。
- `question-concepts-2005-2025-combined.json` は全21年・1,260エントリ。うち1,259件がプレイ対象です。2020〜2025部分は以前のv2から無変更で引き継ぎました。
- `primaryConceptId` を1個、`relatedConceptIds` を任意の数だけ付与。関連概念の空配列は「関連なし」ではなく「精査未完」を意味します。

## 品質・限界
- **暫定分類です。** 問題の設問テーマ・既存タイトルを年度横断で読み、選択肢も重点論点について確認しましたが、900問×5選択肢を独立に網羅的レビューしたわけではありません。
- 広範な・複合的な問題は `needs_option_level_review` としています。他の `provisional_topic_classified` もまだ確定分類ではありません。
- 2005〜2017の既存分類は約12〜14の概念へ雑に集約されているため、このJSONの新しい主概念へ置き換えるまでは「習得済み」の精度が上がりません。
- 2018/2019の年度専用ID（例 `A0.exam2018_q01`）は新データでは再利用可能なIDに置き換えています。履歴を持つユーザーの旧IDを削除せず、明示的な対応付け・移行が必要です。
- 問題本文や試験当時の正答については校正していません。法改正による現行法適合性も別途確認が必要です。

## アプリ側の導入
問題本文のパックと分類データを別管理してください。Workでは分類内容を再考せず、JSON参照の整合・旧履歴互換の検証とデータ登録だけを行ってください。公式試験分野（問1〜25／26〜45／46〜60）と編集上のA/B/Cを混同しないこと。`classificationRevision=3` は問題改版を意味しません。
