# 2019年度 選択肢命題・知識分類のレビュー（Issue #32 / PR #33）

## 対象・実施範囲

- 対象：2019年度60問、選択肢300件、命題レコード300件。既存PR #33の `propositions/2019.jsonl` を設問文込みで再点検。
- 同一命題で条件・否定・数量が結び付いている選択肢は無理に分割せず、各選択肢1命題のまま維持。
- 300件の中心となる知識対象、属性、分類経路を再設定。従来の単語ベースの誤分類に加え、分類木の粒度も統一したため、経路更新件数は300件。すべての旧経路・状態・主語・属性を `classification_revision` に保存。
- 設問文から述語を補う必要がある短文・名詞句40件（問1・3・4・12・14・17・21・48）では `proposition` を補完。変更前の命題も `classification_revision.previous_proposition` に保存し、`source_text` と `question_stem` は一切変更していない。
- 判定状態：`assigned 294 → 300`、`ambiguous 6 → 0`、`unmapped 0 → 0`。

## 分類境界の代表例

| 問題・選択肢 | 判断対象（分類先） | 理由 |
|---|---|---|
| 2019-04（1〜5） | 介護保険 > 加入・資格 > 第2号被保険者 > 特定疾病 | 疾病そのものの病態ではなく「特定疾病に該当するか」を問う |
| 2019-07（4） | 提供体制 > 専門職 > 介護支援専門員 > 法定義務 | 認知症施策という語に引きずられず、設問の中心である専門職の義務に置く |
| 2019-09（1〜5） | 介護保険 > 保険料・財政 > 第1号被保険者保険料 | 年金は特別徴収の条件。年金制度そのものの説明ではない |
| 2019-12（1〜5） | 介護保険 > 地域施策 > 包括的支援事業 > 事業区分 | 認知症支援等の内容ではなく、事業区分への該当性を問う |
| 2019-17（1〜5） | 支援方法 > ケアマネジメント > アセスメント > 課題分析標準項目 | 資産・口腔機能等の内容ではなく、アセスメント標準項目の該当性を問う |
| 2019-21（1〜5） | 介護保険 > 認定 > 認定申請 > 申請代行可能者 | 各施設の固有運営基準と混同しない |
| 2019-24（4） | 支援方法 > 住環境の調整 | 事例での「提案」の妥当性を問う。給付要件そのものではない |
| 2019-48（1〜5） | 支援方法 > 相談援助 > 個別援助と他の援助形態の区別 | 施設名・法律名は行為の背景。問われるのはソーシャルワークの援助形態 |
| 2019-54（1〜5） | 介護保険 > 保険給付 > 居宅介護住宅改修費 | 工事・再支給の可否であり、一般的な住環境調整技法とは異なる |
| 2019-59（3） | 関連制度 > 生活保護 > 介護扶助 | 居宅介護支援の一般基準ではなく、生活保護の介護扶助の特則 |

## 曖昧判定の解消

旧 `ambiguous` の6件は、2019-24/4/1（本人への住宅改修提案）と2019-54/1〜5/1（住宅改修費の制度上の要件）。
前者は「支援方法」、後者は「給付制度」の知識対象として、設問と選択肢を併読した場合に分類先が決まる。分類上の判断であり、**選択肢の真偽や適用法令の時点を裁定したわけではない**。
