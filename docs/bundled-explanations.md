# 内蔵解説の範囲と更新

- 対象：2025年度60問、選択肢300件。各選択肢の正誤理由と、各問の要点を独自に記述。
- 基準：2025年度の設問・試験当時の正答。2026年度以降の制度改正は未反映。
- 表示：○×は回答後のみ、5択は採点後と既存の解答済み問題詳細。回答前のDOMには解説を出さない。
- 参考資料：厚生労働省の法令・運営基準、認定・予防・感染対策・薬剤の資料、国立長寿医療研究センター、法務省、日本ソーシャルワーカー協会等へのリンクを問題別に記録。リンク先は更新されるため、現行のページが試験当時の条文と同一とは限らない。
- 出典は参考資料であり、試験実施機関による公式解説・監修済み教材ではない。各文章は設問の条件に沿った学習用の説明であり、現行法対応の認証は行っていない。

## データを追加・修正するとき

`src/domain/bundledExplanation.ts` の型に沿い、年度・問番号・版・元の設問文・5選択肢の原文・正答組合せのスナップショットを保存する。解説の本文は元の問題データや正答データを変更せず、別フィールドで記述する。参考資料にはURLに加え、分かる場合は条文・項目を記載する。

問題の本文、選択肢、版、正答組合せのいずれかが一致しない場合は、その問の内蔵解説を表示しない。○×表示ではカードの現在の真偽との一致も確認する。過去問の誤答選択肢に現在の制度だけを無条件に当てはめない。

既存の `AppExplanation` による個人の貼り付け解説は独立した機能として残す。内蔵解説の閲覧・開閉によって採点・学習イベント・XP・理解度は変更しない。

## 検証

`tests/bundledExplanation.test.ts` は、全60問・300選択肢の存在、現在の本文との照合、既存の○×データとの一致、改訂時の表示抑止を確認する。

`tests/e2e/bundledExplanation.spec.ts` は、正答・誤答の両方での表示、回答前の非表示、全選択肢の説明、詳細画面、再読込、再練習・次問での非表示、参考資料の開閉時の記録保持、320px幅を確認する。既存の貼り付け解説と用語解説のE2Eも併せて実行する。
