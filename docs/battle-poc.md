# Issue #94: 対戦PoC

## 実装した体験

ホームの「対戦へ」から開始。過去問演習の年度・分類・分野設定を使用し、最大10問の5C2/5C3を出す。既存Providerと完全一致判定（複数正答パターンを含む）を再利用する。

勝敗は **正答数 → 同数なら所要時間 → 両方同じなら引き分け** の順。適当な高速回答で正確な回答を追い抜けない基準として採用したPoC仮説であり、恒久仕様ではない。固定ゴーストは10問中7問正解・320秒。無作為回答でこの相手に勝つ確率は、解答時間ゼロでも約0.000912%（各問の正解確率1/10、独立を仮定）。正確性が完全に優先されるため、速度を競う面白さが弱い可能性は体験評価で検討する。

相手は実在人物を模さず「テストゴースト」と表示。出題列の各位置に固定ログを割り当て、経過時間に応じて進捗を表示する。相手が終了していなくても、既知の全ログと比較してすぐに結果を出す。問題の難しさを推定したログではなく、マッチングやレートは未実装。

問題は未解答優先、同じ条件内では初回校正済み優先、さらに無作為順。過去問演習・○×学習・端末に残った対戦の解答を既出とする。語句や正答を改変しない。法改正未検証・未校正の注記を維持し、復習では既存の用語説明・登録解説・コピー・原本画像を利用する。

## 分離と計測

`src/domain/battle.ts` に抽出した出題・採点・ログ処理と、`src/components/Battle.tsx` の表示で構成。既存のXP、学習履歴、途中の演習セッションは変更しない。

`care-manager-quest:battle:v1` に直近100戦を保存。試合ID、開始日時、問題列、問題バージョン、選択肢、正誤、回答日時、開始からの経過ミリ秒、完了フラグ、連戦数を記録する。各問所要時間は隣接する経過時間の差で算出でき、誤答後の次問の速度も観察できる。中断した試合も保存する。試合開始数・完了数・連戦数の比較は可能だが、再訪率や通常演習との厳密な時間比較はまだ計測していない。

時計は `performance.now()` の差で計測し、描画用のinterval回数に依存しない。短い正誤表示650msと背景滞在も含む。解答をロックし二重登録を防ぐ。別画面への移動・再読み込みは途中終了として扱い、再開はしない。端末が保存を拒否した場合は通知してメモリ上で遊べる。

## 検証と次の判断

- 単体テスト：5C2/5C3・重複/不正選択・複数正答・正確性優先・同点/同時刻・無作為回答の確率・出題優先・破損ログ・保存上限。
- モバイルE2E：10問完走、誤答復習、再戦で未解答優先、既存履歴が不変、時間経過だけで相手が進むこと、中断後に再開しないこと。
- 人による面白さの評価は未完了。自動操作が成功しても「負けてもう一戦したい」の証明にはしない。

実機で3〜5戦し、(1) 負けた直後に再戦したくなるか、(2) 速さが勝負に効く感じがあるか、(3) 相手の進捗が邪魔か支えか、(4) 誤答後に乱打したくなるか、(5) 復習する気になるか、を記録する。この評価後に試合長・勝敗方式・相手の強さを調整する。オンライン化・レート・独立アプリ化の判断は保留し、Issue全体を自動的に完了扱いにしない。
