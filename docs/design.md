# 設計

## データの境界

既存のゲーム・スマホUIを継続利用し、Providerを2025年度の公式問題パックへ切り替えています。UIで外部データを取得したりLLMを呼ぶことはありません。

| モデル | ファイル | 責務 |
| --- | --- | --- |
| 原文 | src/data/packs/2025/questions.json | 安定ID、年・番号・版、問題文、原典どおりの5選択肢、画像・ハッシュ・冊子ページ |
| 原典 | src/data/sources.ts | 問題冊子、正答公表、利用条件のURL・権利者 |
| 正答 | packs/2025/answers.json | 当時の正答番号、必要選択数、出典・照合日 |
| 分類 | packs/2025/classifications.json | revision、主分類、主概念、関連概念、暫定難度 |
| 品質 | packs/2025/quality.json | 文字校正、画像確認、再校正、現行法、独自解説の状態 |
| アダプター | src/data/provider.ts | 上記をQuestionへ結合。本番はofficialProviderの25問のみ |
| 地図 | src/data/knowledge.ts | A/B/C→小領域→概念、関連リンク。分類データから過去問の論点を追加 |
| 解答 | domain/models.ts のAttempt | 問題ID・版、選択、正誤、日時、XP、当時の分類と難度 |
| 概念進捗 | ConceptProgress | 関連問題の学習証拠と本人の理解記録 |
| セッション | Session | 出題ID・位置・選択中・完了状態 |

旧練習問題はlegacy-questions.jsonで保管し、履歴の解析・表示だけで利用します。buildSessionには渡しません。2018〜2024年度を追加するときは年ごとに同じJSON契約のパックを用意し、Provider・履歴用の版アーカイブへ登録します。

分類修正で問題ID・問題versionを変えません。分類revisionを更新します。解答時にconceptIds・classificationRevision・difficultyを記録し、読み込みはこのスナップショットから概念証拠・XPを照合します。現在の分類との一致を要求しないので、分類を変更しても履歴が壊れません。削除・統合した概念の履歴も保持し、将来再集計する場合は明示的な移行処理を追加します。

## 原文と採点

- 2つ／3つの選択肢番号の完全一致で採点。順不同、重複不可、部分点なし。
- 選択肢を並べ替えない。画像とテキストの番号対応を維持する。
- 文字校正済みは問題本文と選択肢を通常のUIで表示。未校正は原本画像と1〜5の番号ボタン。
- 全問で原本画像を参照可能。拡大画像は独立したスクロール領域、別画面でも開ける。
- 現行法への適合性は未確認。当時の公式正答を変更しない。
- 独自解説未登録はその事実だけを表示し、生成しない。
- 主分類・関連分類は暫定、試験センターと無関係。添付のB6は認定有効期間なので既存のB2へ、Cは認知症施策のC2へ接続した。

## 出題・XP・演出

5問の難度目標は `[1,2,3,1,2]`。暫定難度は試験の公的な難度評価ではありません。まず全パックで出題回数の少ない問題を優先し、その中で目標難度を選びます。未探索を優先するときは目標難度を緩めます。25問は最初の5セッションで一巡可能です。各セッション内は重複させません。

正解XP = 30 + 難度×10 + 初見正解20 + min(コンボ−1,4)×10。誤答XP10、200XPごとにレベルアップ。コンボはセッション内、誤答で0。初見は初めて解答した問題。解答IDはsessionId:indexで二重確定を防ぎます。5問回答後にリザルト、次の5問へ進めます。

900msのパーティクルはpointer-events:none。OSのreduced-motionで抑制し、音の失敗で演習を止めません。判定後は短い結果へ即座にスクロールし、操作を待たせません。

## 保存・移行

保存場所は従来のcare-manager-quest:v1を維持し、schemaVersion 2を保存。schemaVersion 1も入力可能です。旧履歴・XP・理解記録・外部URL記録・音設定を維持し、旧問題を含むセッションだけを終了します。初回移行ではcare-manager-quest:v1:before-officialへ元データを一度だけ退避。退避できなければ保存を止め、元データ出力と回復を促します。

JSONは2MB、解答20,000件、外部記録2,000件まで。ID・問題版・選択・日付・採点・コンボ・XP・概念証拠・セッションの整合性を検証し、未知のフィールドを落とします。入力は統合せずプレビュー後に置換。破損データは自動上書きしません。

問題本文・正答の版を変更するときは過去の版を履歴アーカイブへ追加することが必要です。未登録のID／版を含むJSONは安全に拒否します。分類・難度の変更と内容改版は別契約です。

## 概念の理解

問題の正誤と概念進捗は別モデル。未探索＝未回答、学習中＝関連問題に回答済み、習得済み＝異なる2問以上に正解し理解を記録。各概念を個別測定したという意味ではない簡易ルールです。同じ問題の反復だけでは習得になりません。理解記録はXPに影響しません。

解説から論点のモーダルを開いても解答位置は変わらず、閉じると解説へ戻れます。問題画面からも直接論点を参照できます。

外部過去問URLの手動記録は従来どおり正誤とリンクだけを保存し、XP・概念証拠に加算しません。多タブ排他・クラウド同期は今回の範囲外です。
