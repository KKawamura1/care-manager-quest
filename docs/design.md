# 設計

## 境界

`src/domain/models.ts` に問題、解答履歴、概念進捗、セッション、外部記録を個別の型として定義。`QuestionProvider` が取得元の境界です。MVPの `originalProvider` はローカルJSONを読み、ゲームの `buildSession`／`submitAnswer` には問題配列を渡します。将来は許諾済みデータを同じ契約に変換するProviderを追加します。UIから直接外部の問題本文を取得しません。

| 層 | ファイル | 責務 |
| --- | --- | --- |
| 問題 | data/questions.json, provider.ts, sources.ts | 本文、正答、独自解説、版、難度、主分類、複数概念、根拠 |
| 地図 | data/knowledge.ts | 3層分類、概念の説明、概念間リンク |
| ゲーム | domain/game.ts | 出題、採点、XP、コンボ、進行、概念への学習証拠 |
| 保存 | domain/storage.ts | 読込・検証・正規化・失敗報告・外部URL制約 |
| 表示 | App.tsx, components/ | 画面とダイアログ、操作・装飾音・アニメーション |

AppはMVPの画面切替を担います。機能拡張時はHome／Quest／Map／Recordsを別コンポーネントへ移すことが可能です。外部データ、機械的な習熟度推定、同期サービスをAppに混ぜない方針です。

## 出題と採点

- 5問の難度は入口1→標準2→難問3→ひと息1→応用2。適応的難易度調整は未実装。
- 同じ難度では出題回数が最小の問題群からランダムに選ぶ。セッション中は重複させない。
- 5肢から2つ又は3つを選ぶ。順不同の完全一致で正解。部分点なし。
- 指定数に達するまでは確定不可。上限以上は選択されないので、先に解除する。
- Attempt IDは `sessionId:index`。二重確定は無操作。確定前の「次へ」も無操作。
- 初見とは、この問題に初めて解答したこと。初見の誤答後に正解しても初見ボーナスは付かない。

## XPとレベル

正解のXP = 30 + 難度×10 + 初見正解20 + min(コンボ−1,4)×10。誤答でも探索XP10。コンボはセッション内、誤答で0。正解1問目は1コンボ。合計XPは履歴から導出し、別の累積値を保存しない。200 XPごとにレベルアップ。Lv.3で「認定の探究者」称号を表示。レベルによる問題のロックはなく、称号は演出です。

## 概念の進捗

問題正誤のAttemptと、ConceptProgressを分離します。

- 未探索：関連問題にまだ解答していない。
- 学習中：関連問題に解答済み。
- 習得済み：その概念に関連する**異なる2問以上**の正解と、本人の「理解を記録」の両方がある。

同じ問題の反復正解だけでは習得になりません。理解の記録はXPに影響しません。複数関連概念に証拠を付けるため、各概念を個別に測定したという意味ではありません。推定モデル導入時は正誤履歴と概念IDから新しい推定結果を別バージョンで計算します。

C領域は構造だけを表示し、問題追加を予告。未実装領域をレベルで実際に解放できるような表示にはしません。

## 保存と可搬性

`care-manager-quest:v1` にschemaVersion 1のPlayerStateを保存。セッションの出題ID、位置、選択肢、完了状態を含み、深掘りは表示状態だけなので閉じても演習位置が変わりません。

JSONは文字列長・配列長・ID・版・日付・URL・選択肢・セッション整合性を検証。採点、初見、コンボ、XPと概念の正誤証拠はローカル問題から再計算して照合します。未知のフィールドは正規化時に捨てます。入力は2MB、解答履歴は20,000件、外部記録は2,000件まで。JSON読み込みは統合せず置き換えます。

壊れたlocalStorageは自動上書きしません。元データの書出しと明示的な再開始が可能。保存容量不足や無効化は画面に表示し、現在のメモリ履歴のJSON退避を促します。多タブ排他と大容量履歴は今後の課題です。

現在の問題版に一致しない旧履歴は安全に拒否します。問題改訂時の履歴移行・旧版アーカイブはロードマップに含めます。

## 外部サイト

個別問題のcanonical HTTPS URLと表示名、正誤、日時のみ。`keamane.kakomonn.com/questions/数字` のURL以外は拒否し、認証情報・ポート・query・fragmentも拒否。HTMLは挿入せずReactのテキストとして表示。外部リンクはnoopener/noreferrer。結果はゲームXP／概念証拠に加算しません。問題の分類・正答を取得していないためです。

## アクセシビリティと演出

ネイティブbutton、ラベル付き入力、aria-pressed、status、dialogを使用。ダイアログのフォーカストラップはブラウザ標準に委ね、閉じると開いた要素へフォーカスを戻す。正誤は色だけでなく記号・文言で示す。パーティクルはpointer-events:none、900msで終了。reduced-motionでは抑制。音声非対応・再生失敗は演習を止めません。外部フォント・画像・解析は読み込まず、装飾はCSS/SVGとWeb Audioで生成します。
