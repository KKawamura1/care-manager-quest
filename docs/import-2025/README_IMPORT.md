# Care Manager Quest — 2025年度（第28回）介護支援分野25問

## 内容

- `data/care_manager_2025_support.json`: 問題文・5選択肢・正答・必要選択数・分類・原典リンク・検証状態
- `assets/questions/2025/q01.png` 〜 `q25.png`: 添付の公式試験問題PDFから各設問をそのまま切り出した画像
- `verification_report.txt`: 自動検証結果と未完了の品質チェック

## 重要な品質上の注意

- 全25問にテキストが入っていますが、OCR補助の転記であり、1字単位の原本照合は未完了です。**ゲーム画面では原本画像を表示することを初期設定**にしてください。校正が完了するまではテキスト表示を正式な正本としないでください。
- `correct_choices` は前回の「公式正答表に照合済み」索引から引き継いでいます。添付PDFには解答表が含まれないため、今回は再照合していません。
- `current_law_status=not_reviewed`: 法改正への適合性は未検証。2025年度試験の当時の正答として採点してください。
- `independent_explanation=null`: 一言解説も含め未作成です。AIの未検証の解説を公式と誤認させないでください。
- 分類は暫定であり、知識マップとの関係は今後レビュー可能にしてください。

## UIの推奨（MVP）

- 問題表示には画像 (`image_path`) を優先。5つの数字の選択ボタンを画像の下に並べる。
- `required_choices` に応じて2/3択の複数選択を受け付ける。順番を変更して解答番号がズレないようにする。
- 回答後に `correct_choices` と照合し、初見正解・XP・コンボのエフェクトを付与。
- 解説未登録のときは捏造せず、「公式問題の原文を見る」「知識マップを見る」「次の問題へ」とする。
- 公開時、題名・出典・権利者・独自解説の免責を表示。
