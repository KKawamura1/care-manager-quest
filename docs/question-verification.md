# 2025年度公式過去問の取り込み・確認台帳

確認日：2026-10-10。出典：公益財団法人 社会福祉振興・試験センター。ユーザー提供ZIPを起点に、東京都福祉局の[公式問題PDF](https://www.fukushi.metro.tokyo.lg.jp/documents/d/fukushi/r7shikenmondai)と[正答公表画像](https://www.fukushi.metro.tokyo.lg.jp/documents/d/fukushi/r7seitoubangou1-25)を取得し確認しました。
