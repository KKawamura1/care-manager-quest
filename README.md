# Care Manager Quest

知らない問題を推理で攻略し、点だった知識をつなげるスマホ向けWebゲーム。資格取得のための模試ではなく、介護保険の世界を探索するためのMVPです。

**GitHubのこのリポジトリがソースの正本です。privateを維持し、mainへのマージは手動で行います。**

## 遊び方

1. 「5問のクエストを始める」を押す。
2. 指定された数の選択肢を選び、解答を確定する。
3. 短い解説を読み、すぐ次へ進むか「詳しく理解する」で掘り下げる。
4. 5問のリザルトでXP・コンボ・初見突破を確認する。
5. 知識マップで概念のつながりを見る。記録タブから履歴をJSONで持ち出す。

深掘りを閉じると元の位置へ戻ります。中断・再読み込み時も、選択中／解答済み／リザルトの状態を復元します。効果音は右上で切り替えられ、OSの「視差効果を減らす」等に合わせて派手なアニメーションを抑制します。

## 開発

Node.js 22以上、npmを使用します。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

同じネットワークのiPhoneから、開発端末のIPと表示されたポートを開けます（開発サーバーは0.0.0.0にバインド）。HTTPSでの本番配信では音声を最初の解答操作で開始します。iPhone実機のSafariでの音声・触感は別途確認してください。E2EはiPhone 13相当の390×664、タッチ・DPR設定でChromium/WebKitを検証します。

## MVPの範囲

- React + TypeScript + Vite。サーバー・DB・APIキー・LLM API不要。
- 独自の五肢複択問題25問、2つ／3つ選択、5問単位。
- 難易度の緩急 `[1, 2, 3, 1, 2]`。同難度では未出題／出題回数の少ない問題を優先。
- XP、レベル、セッション内コンボ、初見正解、短い音、操作を妨げないパーティクル。
- A・B領域の23概念と、将来のC領域。最上位→小領域→概念の3層。
- 正誤と概念の理解記録は別モデル。習得表示は簡易ルールで、統計的推定ではない。
- localStorage自動保存。スキーマ検証付きJSONの出力／入力。壊れた保存データの退避。
- 外部サイトの個別問題URLと手入力した正誤のみを記録。XP・習得には混ぜない。

## 問題・権利・法令

問題本文・選択肢・解説は本プロジェクトで独自作成。過去問サイトから取得・転載していません。公的資料の確認日、条項、URLを各問題に付け、選択肢ごとの正誤根拠を説明しています。

## 保存と制約

履歴はブラウザ・配信元URLごとに保存されます。プライベートブラウズやサイトデータ削除では失われることがあります。JSONの入力は2MBまで、現在の問題ID／バージョンに対応するschemaVersion 1のみ。読み込みはプレビュー後に明示的に置き換え、必要に応じて現在の履歴を先に書き出せます。多タブでの同時編集やクラウド同期はMVP対象外です。

## CI

GitHub Actionsで型チェック、Vitest、本番ビルド、スマホ相当のChromium/WebKit E2Eを実行。ビルド成果物とテスト画面はArtifactsとして保存します。privateリポジトリでもActionsは設定・契約枠の範囲で利用できます。公開化は行いません。
