# Care Manager Quest

ケアマネ試験の**2005〜2025年度の過去問1,259問**で学べるスマホ向けWebアプリ。5択の「過去問演習」は得点を確認するシンプルな出題モード、○×学習は選択肢ごとの復習モードです。

**[▶ Care Manager Quest をプレイ（本番サイト）](https://care-manager-quest.focusgate-kkawamura.workers.dev/)**

GitHubがソースの正本です。mainへのマージは手動です。CloudflareのGitHub連携により、main更新 → Cloudflare側で型チェック・単体テスト・ビルド → 自動デプロイ。**サイトは一般公開・GitHubリポジトリはprivate**です。Cloudflare Accessは使用しません。以前のChatGPT Sites版からの学習履歴移行は[セットアップ・履歴移行手順](docs/deployment.md)を参照してください。

## 過去問演習

1. 「5問の演習を始める」を押す。
2. 指定された2つ／3つの選択肢を選んで確定する。番号は原典どおり1〜5、順不同の完全一致で正解。
3. 正誤・正答・解説を確認して「次の問題へ」または「詳しく見る」。原本画像と知識マップの論点を参照できる。
4. 5問終了時に正解数・正答率と各問の結果を確認。「もう5問解く」で続ける。
5. 記録タブから履歴をJSONで持ち出す。

出題は難易度順には並べず、回答回数の少ない問題を優先してランダムに選びます。過去問演習中はXP・コンボ等のゲーム演出を表示しません。

全年度の本文・5選択肢を通常のテキストUIで表示します。初期設定は2025年度・全分類。ホームで年度と「大分類→中分類→小分類→引き出し」を選び、上位分類の配下全体でも学習できます。5択は該当する選択肢を含む設問を重複なく出題し、該当設問が5問未満なら1〜4問で終了します。試験分野は追加の絞り込みとして利用できます。原本画像が未同梱の問題は公式PDFまたは問題掲載元から確認できます。

独自解説は全問未登録です。未検証の説明を生成して埋め込むことはありません。正答は**各年度の試験当時**のものとして採点します。現行法への適合性は未確認です。

## ○×スワイプ学習

問題文・選択肢の点線下線が付いた用語をタップすると、短い用語解説と出典が開きます。解答前後どちらでも使え、閉じると同じカードに戻ります。解説は登録済みの基本用語が対象です。用語の一般的な意味を示すもので、設問の正誤や試験当時の制度を判定する説明ではありません。

ホームの「○×学習」で年度・4階層の分類を選び、右スワイプで○、左スワイプで×、上スワイプで「わからない」（誤答扱い）。解答後は上下にスクロールして解説を読めます。正誤エフェクトと解説を確認してから、左右スワイプか「次のカードへ」ボタンで次へ進みます。ボタンと左右・上キーでも操作できます。既存の選択肢○×データを使う6,289枚で、元の設問文も表示します。20枚などの区切りはなく、好きなところで中断・再開できます。

○×と5択は共通の選択肢単位の回答履歴・XP・知識マップを使います。5択は5枚の○×を一括回答として記録します。日本時間の1日最初の回答だけを習熟度とXPに加算し、同日の再練習は無加点です。直近2学習日の重み付き正答率を学習レベル（1回正解で約67%、2連続正解で100%）とし、経過時間と習熟度から復習時期を決めます。回答履歴のJSON入出力は「記録」タブに一本化しました。

知識マップ・5択・○×は、PR #68/#70の「5大分類→28中分類→小分類→引き出し」の分類を共通で使います。○×は選択した階層に属するカードだけ、5択は該当選択肢を含む設問全体を出題します。複数の引き出しに属するカードや設問も、上位の対象件数には1回だけ数えます。親の分類を変更すると下位の選択は解除され、「配下すべて」でその親全体に戻れます。両モードの分類選択は個別に保存し、年度変更では維持します。対象0件の場合は開始できませんが、中断中の演習は元の問題で再開できます。

分類の意味レビューは継続中です。分類を本番で使うことと、分類内容・試験の正誤・当時法令の確認完了は別です。改善は年度別の正本に反映し、ビルド時に本番用データを再生成します。

## ChatGPTに質問して、短い解説を保存する

5択・○×とも「問題をコピー」で、問題文・選択肢・短い解説依頼文をコピーしてChatGPTに貼り付けられます。ChatGPTには「問題文と選択肢の再掲 → 背景を含む自由な解説 → アプリ用の短い解説」の順で回答を依頼します。○×では対象の選択肢を明示し、回答後はカードの○×判定と自分の解答も含めます。回答前は正答を含めません。自動コピーが使えない場合は、全文を選択して手動コピーできます。

1. ChatGPTが返した問題文・選択肢と背景解説を読み、最後のJSONコードブロックにある「アプリ用の短い解説」をコピーします。ブロック全体でも、中のJSONだけでも構いません。
2. アプリの解答後、または5択の詳細画面で「短い解説を貼り付ける」を開き、貼り付けて「短い解説を保存」を押します。
3. 保存した解説はその問題・○×カードの解答後に表示され、次回の学習でも読めます。「短い解説を貼り替える」で更新でき、削除もできます。

5択は問題全体、○×は選択肢ごとに保存します。別の問題・選択肢や古い版のブロックは受け付けません。問題の版や○×判定が変わった場合は古い解説を表示せず、再生成を案内します。解説は600字以内のテキストとして表示し、HTML等は実行しません。

解説は自分で登録した内容であり、アプリの公式解説・正答データを変更するものではありません。保存は同じURLの同じブラウザ内のみで、履歴JSONには含まれません。別端末への同期はなく、サイトデータを削除すると消えます。

## 開発

Node.js 22.18以上、npm（分類用TypeScriptモジュールの標準実行に必要）。サーバー・DB・APIキー・LLM APIは不要です。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

iPhone実機は同じネットワークから開発端末のIPとポートへアクセスできます。E2EはiPhone 13相当の390×664・タッチ設定でChromium/WebKitを起動します。実機Safari・音声・指操作の確認は別途必要です。

## 保存とデータ設計

- 問題本文・原典・正答・分類・品質状態・履歴は分離。静的JSONをProviderで結合します。
- `2025-01`〜`2025-25`は分類から独立したID。問題の版番号は内容・採点契約用、分類のrevisionは別です。
- 回答イベントは選択肢ID・真偽・回答時刻・モード・獲得XPを保持。知識マップは現行の選択肢分類へ投影する。
- localStorageに自動保存。JSONの入力は2MBまで、プレビュー後に明示的に置換。
- schemaVersion 3を使用し、旧保存キーからの後方互換移行はしません。旧データは旧キーに残ります。
- 旧練習問題は履歴参照専用アーカイブで、本番の出題対象に入りません。
- 保存が壊れた場合は自動上書きせず、退避・回復操作を表示。

履歴は配信元URL・ブラウザごとに保存されます。プライベートブラウズやサイトデータ削除では失われることがあります。多タブ同時編集・同期・大容量履歴は今後の課題です。

## PR33の分類を本番で使う

分類の正本は `docs/taxonomy/issue-32-experiment/propositions/YYYY.jsonl` の21ファイルです。正規化ルールは `scripts/issue32-drawers.mjs` と関連する型付き定義にあります。`scripts/prepare-taxonomy.ts` がGit管理外の本番用 `src/data/packs/knowledge.json` を生成し、`prepare:questions` で全Providerへ結合します。

旧分類のカタログと検査専用データは削除しました。現在は選択肢別の分類が知識マップの正本です。○×と5択の学習記録を共通化したため、以前の学習履歴形式は新アプリへ自動移行しません。登録済みの短い解説は別の保存領域で管理します。

```sh
npm run prepare:questions
node --experimental-strip-types scripts/prepare-taxonomy.ts --check
```
